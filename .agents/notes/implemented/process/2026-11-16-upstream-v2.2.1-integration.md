# Agent Note: 合并上游 v2.2.1 并记录云网页连接复用限制

Status: implemented

## Problem

本地 `main` 位于 `247740a1`，与 `try2love/codex-mobile-bridge` 的 `main` 已分叉；本地有 27 个独有提交，上游有 75 个独有提交。用户要求拉取上游 `main`，冲突以上游为准。上游当前提交为 `1004e5ae`（v2.2.1），文本合并涉及四个冲突文件，且本地云网页回归依赖其中一段被上游版本覆盖的连接处理。

## Decision

以普通双亲合并保留双方历史，使用 `-X theirs` 选择上游冲突内容，保留不冲突的本地改动。合并前的本地状态由 `backup/main-before-upstream-20261116-247740a1` 分支保存。

`bridge/api/httpd.py`、`desktop/index.html`、`tests/browser/playwright.config.cjs` 和 `web/shared/creation-model-picker.js` 的冲突均选择上游。模型目录失败采用上游的普通状态提示与手填入口；本地已有回归只同步提示断言，继续检查显式重试、缓存选择保留以及旧请求不能覆盖新作用域。

HTTP 处理器采用上游 `output` 实现，不恢复本地原有的“非 GET/HEAD 错误响应统一关闭连接”分支。这一选择遵循本次明确的冲突优先级；它使云网页在未知 POST 返回 404 后复用连接的场景存在已知失败，不能将本次同步报告为云功能全部通过。

## 记录归属

检索活跃 proposed、implemented、rejected 中的上游优先、HTTP 转发和拒绝请求体处理，相关记录均为 implemented：

- [共享中继与云 HTTP 分别校验](../architecture/2026-11-14-shared-relay-cloud-framing.md)：部分重叠，两类链路各自的校验职责继续成立。
- [共享创建模型](../feature/2026-11-04-shared-creation-model-selection.md)与[上游模型目录失败回退](../bug-fix/2026-11-14-model-catalog-manual-fallback.md)：部分重叠，创建意图与账号身份隔离继续有效，失败提示采用上游现有行为。

没有完全吸收的记录或需要拒绝、归档的提案。

## Alternatives considered

- 恢复本地错误响应关闭连接的分支可以保留原云网页连接复用保障，但会重新引入本次冲突中被上游版本覆盖的行为，因此本次同步不采用。
- 将本地 `main` 整体重置到上游可以得到完全一致的文件树，但会移除本地独有提交；用户要求合并冲突以上游为准，没有要求丢弃所有本地功能，因此采用普通合并。
