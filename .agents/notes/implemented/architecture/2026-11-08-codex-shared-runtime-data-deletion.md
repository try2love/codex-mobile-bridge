# Agent Note: 以原生数据删除为准的 Codex 共享接入

Status: implemented

## 问题

原 App 持有父聊天时，独立元数据进程无法创建附属聊天或删除目标。此前隔离实验已经证明共享运行时能够执行这些操作，但原 App 打开的侧边标签没有外部关闭接口。要求同时关闭原 App 标签会阻止交付已经可用的数据操作。

## 决策

用户确认以目标原生数据真正删除为准，不以关闭原 App 已打开标签作为阻断条件。本决定部分替代[共享运行时与标签同步提案](../../proposed/architecture/2026-11-08-codex-shared-desktop-runtime.md)的验收边界；旧文保留原始证据和标签限制，不将其改写为已经实现标签同步。

默认本机 Codex 的账号管理复用现有控制流程，提供显式的原生连接初始化。先核验已安装 CLI 的 Unix transport 和 proxy 能力，再核验任务、默认配置目录和唯一 App 进程，正常退出后通过原 App 支持的 CLI 路径配置启动透明适配器。不修改原 App 安装包，不复制账号，不直接写原生数据库。当前仅对已验证的 macOS 开放；独立 Codex 配置、VS Code 与 Windows/Linux 保留原接入。

适配器由原 App 持有，保留原始初始化与其他配置，仅将主要运行时的 stdio 转为同用户私有 Unix socket。其他 CLI 命令、启动配置探测和辅助初始化透传。Bridge 只在用户明确创建或删除时临时连接同一个运行时；断开该连接不结束原 App。配置只有在由网关启动 App 时生效，普通启动未共享时明确拒绝另起 writer。

## 身份与事务

- 配置和运行记录使用私有权限及原子写入。socket 所在目录为 0700，实际 socket 为 0600。兼容原生将广告路径链接到 `/tmp/codex-daemon-UID` 的形式：对规范化父目录与文件名的 OS 路径字节计算 SHA-256，严格校验链接目标、保护目录权限及 socket 身份；不修改链接或真实 socket 权限。握手前后校验 inode 与进程世代。
- 运行记录绑定配置目录、App、适配器、原生进程世代和 socket。启动中与就绪分开；启动结果未知或子进程仍在时不启动第二个 writer。原 App 退出时正常终止所属运行时，不强杀。
- 同一配置目录的初始化、账号切换／恢复与元数据写入使用同一按需互斥，覆盖连接、操作、断开，避免生命周期操作打断写入。产品以单网关为设计前提；Release 与 Test 并行仅为验收环境，锁不增加常驻监听。GUI／IPC 退出后，有界等待适配器和原生运行时正常收尾，再写配置或启动；超时不覆盖账号、不自动回滚重启、不强杀。
- 创建与删除继续复用既有权限、任务、后代范围、确认与持久账本。明确未发送可重新确认；已发出但结果未知不自动重放、不降级到另一个运行时。
- 成功后只发送真实 Bridge 身份的 attached 查询缓存失效通知。不伪造原生 owner、归档或删除广播。原生数据及历史存在性核对决定删除结果，原 App 未关闭的空标签是已知显示限制。

## 备选方案

独立短期元数据进程改动最小，适合未被持有的历史，但无法解决当前 active writer 冲突，未初始化时仍保留原有路径。全局 WebSocket 地址可以省掉适配器，但已安装原 App 会禁用部分本机 IPC/协调，因此不采用。通过修改原 App 界面或伪造事件关闭标签会扩大维护和身份风险；用户已接受以真实删除结果为准，不采用。

## 验证

源码生产路径在 macOS 原 App 26.1103.41825（原生 CLI 0.167.0-alpha.3.2）通过隔离验收：用户打开父聊天并取得真实 Desktop owner 后，`fork_attached` 创建附属关系；Bridge 断开重连保持同一运行时；`delete_native` 后原生列表、数据库与 rollout 均不再存在目标；父聊天及 owner 保持不变。隔离 App 正常退出后运行记录清除，主 App 未退出。仅向 127.0.0.1 固定回显发送一次种子输入，无真实模型调用。

针对运行时身份、私有原生链接、启动失败记录和消息容量的 32 项回归通过；新增退出等待、超时保留与仅配置后等待的 3 项测试通过，账号生命周期锁及受影响切换／恢复路径通过定向回归；账号 UI 的 67 项测试已通过且源码未变，不重复执行。此前用户已确认 Bridge 创建的原生侧边聊天能在隔离原 App 查看；真实删除成功后打开标签残留的限制保持不变。代码提交 `85b3f87` 的 Mac Test `2.2.0-test.20261108.rc4` 已签名、安装并运行于 8788：冻结网关在禁用全部 Agent 的独立资料下 1.527 秒就绪，认证与网页资源哈希一致并正常停止；冻结适配器在隔离原 App 中读取原测试历史、断开重连保持同一运行时、正常退出完成收尾，未发送模型消息。安装保留 36 个受保护配置文件及 rc3 回退包，局域网与固定 HTTPS 均返回最终资源和原认证边界。主 App 接入仍为未初始化，因现有运行与待决策任务而未重启；不将成品安装等同于主 App 已切换。

## 影响

共享模式新增一个由原 App 持有的透明适配器和本机字节代理，有额外进程与序列化开销；未初始化时不运行它们，未新增后台轮询。初始化需要原 App 空闲并正常重启一次。当前主 App 尚未切换；跨平台和普通外部启动自动沿用共享设置不作为已通过项。
