# Agent Note: 按接入实例复用管理页面与聊天导航

Status: implemented

## 问题

同一种 Agent 可以有多个独立配置，按 provider 区分页面不足以表达账号、项目和会话归属。ZCode、WSL 的管理弹窗与已有下一级页面不一致；手机实际使用的分主机列表仍将独立 Codex 配置并入默认列表。导航状态刷新重建底部节点，切换或隐藏页面后可能丢失水平滚动位置。

## 决策

共享外壳使用稳定的接入 ID 标识所选客户端；provider 只决定使用哪套已有协议和功能组件。桌面 `GatewayLayout` 负责管理页面、可见性和返回路径。已有 Codex、Claude、DSH 表单保持复用；其他接入按同一页面容器挂载账号组件，WSL 复用其原账号组件。管理入口不按客户端另造弹窗，切换到其他页面后不继续刷新隐藏的账号面板。

默认 Codex 的聚合查询和分主机 HTTP 查询共同使用 `codex_list_hosts`：包含默认本机及已启用 SSH/WSL，不包含独立 home。默认会话列表在数据库分页前排除 IDE 来源；独立配置仍可列出其原 VS Code 和 CLI 会话。项目、创建请求、执行连接及账户继续复用原业务，以所选入口隔离；浏览器历史恢复也恢复入口 ID，不能只恢复 provider。

首次加载从保存的导航选择恢复时，同时初始化操作目标 host。仅恢复标题与列表筛选会导致新建表单继续指向默认配置；再次点击已选入口也不会触发切换。因此启动状态与用户切换使用同一入口身份，不要求用户先切走再切回。

会话分类同时读取原生 `thread_source` 与 `originator`。明确标记为 CLI 的原生创建记录，即使保留 `Codex Desktop` 创建者，也按 CLI 读取和执行；真正的 VS Code 来源仍为 IDE，子代理仍被排除。不改写数据库记录，也不取消独立入口对 Desktop owner 的隔离限制。

`ClientNavigation` 保留按 ID 建立的底部按钮，不因状态轮询重建。共享导航容器移入另一个列表或重新可见时恢复已保存的位置；无布局变化时不写滚动位置，用户输入取消待执行的恢复。两侧箭头和渐隐只在对应方向存在隐藏内容时显示，不增加请求或轮询。顶部标题在至少两个实例启用时打开共享选择菜单，顺序与现有客户端顺序一致，包含被用户隐藏底部图标的启用实例。选择当前实例不重载列表。

## 备选方案

- 每个 provider 维护管理页面、底栏和菜单：适配快，但各端容易再次出现行为差异，也无法统一多配置身份，放弃。
- 每次刷新重建按钮再恢复 scrollLeft：原实现改动少，但隐藏和跨容器移动时可能读取到零；保留节点，并将位置恢复限制在布局变化时。
- 删除独立入口的 APP 拒绝条件：可以绕过新建故障，但会掩盖来源误判，放松原 owner 边界；修正共享分类层。
- 只修聚合列表：单元入口较少，但手机实际读取分主机 API，不能解决已复现的混入；两个入口复用同一范围规则。

## 验证

- 共享来源和配置隔离回归检查原生 CLI 元数据、IDE 过滤、分页、默认 APP/CLI/WSL 和独立主机 HTTP 范围。
- Chrome、WebKit 的 390px 浏览器检查实际滚动输入、顶部菜单、独立 A/B 切换、状态刷新、跨 provider 移动、隐藏后恢复、隐藏底部图标的入口可达。真实桌面 HTML、布局和账号组件检查六类入口均使用下一级页面，API 为合成夹具。
- 原生 Codex CLI 在专用临时 home 中新建项目及聊天，实际产生 `originator=Codex Desktop / thread_source=cli`；两次合成响应发送均完成，约 0.52 秒，释放后被动列表不接回，再主动连接成功。默认凭据摘要不变。此项只证明原生协议链路，不代表上游模型网络已验证。
- 最终 Mac Test `2.1.7-test.20261102.client-shell.3` 的实际浏览器验证：刷新后独立入口的新建表单仍指向其配置；通过共享目录选择器新建专用项目和 CLI 聊天，局域网发送及 HTTPS 续发均收到真实上游回复。沿用该配置已有 `gpt-5.6-luna`；两种访问方式的默认列表均排除独立配置和 IDE，专用项目只登记在独立配置。没有修改默认账号或重启原 Agent。
- 本轮源码、安装包与安装后记录位于本地 `.tmp/client-shell-20261102/`，不提交运行数据和截图。Windows/Linux 及手机真机不以本次 Mac/WebKit 结果代替。

## 影响

新增接入复用导航、可见性和管理页面，仍按实际能力挂载账号与聊天功能。没有新增自动重试、定时请求或第三方依赖。主动释放保持原有 `detached` 语义：网关已取消订阅，原生服务可能仍持有 writer，不能宣称已完全卸载。
