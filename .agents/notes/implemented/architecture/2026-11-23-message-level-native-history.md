# Agent Note: 手机存档按消息读取并与实时请求分离

Status: implemented

## 问题

已传输会话的原生存档以整回合 JSON 保存。最近页先取回合再解码，指定消息和正文查找也遍历回合；Android 还多次读取 SQLite 文本片段再拼接。回合包含大量过程或长正文时，缓存读量随历史增长。网页首次请求在原生 seed、清理协调及条件探测之后才发出，缓存的慢路径因此影响实时内容。

## 决策

`turns` 保留回合身份、日期和清理标记；消息写入 `archive_records`，正文写入 `archive_parts`，服务端删除保留于 `archive_deleted`。每条消息独立按 key/version/synced 覆盖，同版本较早正文只能补缺，不替换更新内容。正文按 Unicode scalar 偏移分成最多 16000 字的块，首屏正文预览最多 6000 字。最近主线和过程区间使用独立索引及稳定 keyset 游标；最近页最多 40 条、目标 192 KiB，单条元数据大于预算时仍保留一条，避免无法翻页。

过程子项不在首屏解码，原生页提供过程入口，展开后按区间和游标读取；指定正文按 key/version/offset 直接查询。离线页继续使用共享聊天渲染器，已回答交互折叠、最终回答、附件和正文展开沿用现有展示。旧原生壳仍可使用已有网页兼容路径，新能力以 `recordPages:1` 识别。

旧 `turns.content` 由原生串行队列每次转换一回合，并在批次间让出执行机会；优先处理当前会话。消息、正文和清除旧 JSON 在同一事务提交，失败保留原件。转换只使用旧记录自己的时间，不能覆盖更新的实时消息，也不能复活较新的删除标记。新数据不再写整回合 JSON。

手机前台网络读取只使用有界内存中的版本提示，不等待原生认证回调、旧缓存导入、状态查询或落盘。响应直接显示，持久化另行核对账号代际及原生清理版本。初始化发现的已有清理记录不使新取得的手动首屏失效；新发生的清理仍使在途结果失效。原生最近页与网络并行提供本地预览，预览不授予发送、审批、停止或文件操作权限。原 owner/provider/auth/cwd 不变。

## 备选方案

保留整回合 JSON、只加最近回合索引，能减少全表排序，却仍需解码一个大回合才能得到少数主线消息。只给现有缓存调用增加超时，可以让界面继续，但不能解决读放大及离线读取本身变慢。完整更换网络协议会扩大客户端与网关兼容范围；当前网络已具备按消息版本、区间和正文偏移读取的协议，因此沿用它，先替换原生存储及前台等待链。

## 影响

新增消息和正文索引占用少量存储；旧数据首次转换有一次性 CPU、临时空间与事务写入成本。原件只在成功提交时清除，坏记录保留并报告读取失败，不能伪装为完整空会话。无内容可读且转换仍在进行时，离线入口进行有界等待，超时提供重试错误。

清理、账号隔离、会话 epoch、撤销登录、日期范围、附件别名及未知写入不重放的规则继续保留。网络断开仍通过原生只读入口浏览；联网后使用当前网关的元数据与权限，增量补齐显示及存档。

## 既有笔记审计

[主动历史传输](../feature/2026-11-23-history-transfer-from-22bce.md)与本篇部分重叠：传输清单、分段校验、资料清理、附件引用及原生权限边界保留，原生整回合保存和首屏等待链由本篇替代。[共享历史缓存](../feature/2026-11-16-shared-history-cache.md)继续说明旧网关回退路径，与本篇不是同一存储入口。检索没有同题未决提案。

## 验证

生产 Swift 存档夹具覆盖 2000 条记录的大回合、消息/过程分页、正文直接读取、约 5 MB 旧正文转换及 Unicode 原文还原、失败事务保留、删除与版本保护、日期清理和物理回收。共享脚本回归覆盖原生请求永不返回时仍显示网络内容、内存版本增量复用、初始化旧清理记录及在途清理失效。

直接执行生产最近页 SQL：历史由 100 增至 10000 回合，返回窗口仍为 41 条候选，SQL VM 步数为 973 与 932，无临时排序。两端 schema 对照通过。Chrome/WebKit 的宽窄屏回归验证本地预览先于被延迟的网络首屏、原生缓存挂起不阻塞在线内容、原生分页过程及正文展开。iOS 模拟器目标编译、Android Java 编译通过；这些不代表 Android/iPhone 真机加载耗时已验收。Test 安装与包路径另见本轮交付证据。

## 连接前首屏的等待边界

初次网络响应仍在读取且内容为空时，不使稍后返回的本地预览失效。当前页面已取得的最近消息直接提供内存预览；旧资料正在转换但尚无可见记录时，原生预览最多30次、间隔150ms重查，网络读取独立进行。回调仍核验账号、scope、generation和访问epoch；当前会话已失效便停止，不让迟到结果覆盖新聊天。连接中的首屏及转换后出现的本地记录由共享脚本和Chrome/WebKit宽窄屏回归覆盖。
