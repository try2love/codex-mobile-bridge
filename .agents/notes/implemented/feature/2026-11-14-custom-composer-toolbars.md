# 输入区自定义工具栏

## 行为

输入区采用轻量一体样式：上下工具栏与文本框置于同一个圆角边框内，文本框使用透明背景，常用图标与发送键保留 44px 点击区域。Codex 与其他客户端共用该结构，颜色跟随明暗主题。

聊天输入区共用上下两条工具栏。工具面板入口可在上下栏左右四个分区移动和排序，主操作固定在下栏右侧。上栏没有可见工具时自动隐藏，将常用工具和面板入口放到下栏即可形成单栏。面板入口始终保留在工具栏中，配置校验会将缺失或误收纳的入口恢复到上栏左侧，定制页禁止将入口拖入或移动到面板自身。旧配置保留原工具排列并补齐入口。模型与思考强度、Skill、权限、上下文、附件、发送方式、计划、目标、收起，可在上下栏左右分区和工具面板之间移动。工具面板展示收纳其中且显示方式为可见的工具，客户端能力仅影响可用状态；加号菜单提供 Skill 快捷入口，独立 Skill 工具可在工具面板和工具栏之间移动。

默认上左为工具面板入口、权限，上右为上下文、收起，下左为附件、模型，工具面板为 Skill、发送方式、计划、目标。加号菜单包含文件、图片、项目引用和 Skill，Skill 使用原选择器和客户端能力校验。各工具支持仅图标、仅文字和图标＋文字。固定在右下角的发送键也支持三种显示方式，默认图标＋文字；定制页点选发送键后调整样式，位置保持固定。此样式统一作用于发送与停止状态，运行中有草稿时发送方式展开入口继续显示。模型保留名称和思考强度；权限保留客户端标签与状态图标；上下文保留用量、详情和压缩入口。

普通工具增加「隐藏」显示方式，选择后自动收纳到工具面板，并从日常工具栏及工具面板隐藏。定制页继续显示带有隐藏标记的工具，支持改回可见样式；把隐藏工具拖动或移动回任一工具栏时，恢复该工具的默认显示方式。面板入口与发送键保留三种可见显示方式。隐藏仅控制展示，底层客户端能力与功能状态保持原语义。

发送方式为同源浏览器跨聊天共享的偏好。空闲主按钮显示发送，Bridge 提交 `mode: send`；运行中有草稿时按偏好和客户端能力计算动作，显示发送方式和展开箭头；运行中没有草稿时显示停止。附件和引用计入草稿。展开菜单与发送方式工具共用排队和引导两种后续发送偏好，展开菜单另提供停止。普通发送由空闲状态推导，保留客户端发送能力校验；运行中两种后续动作均不可用时禁用发送。选择方式仅更新偏好，主按钮负责执行；停止保留草稿。能力限制触发动作回退时，两处入口显示同一个有效动作，持久化偏好保持原值；能力恢复后重新采用该偏好。实际消息提交显示发送中，其他忙碌操作禁用控件。

收起隐藏输入区主体，保留展开入口、草稿和光标。面板入口位于下栏时，收起会临时把入口显示在上方，展开后回到保存的位置；布局设置保持用户选择。打开聊天、添加提示或图片、出现发送错误时展开。引用选中文字使用独立紧凑行，保留原生复制和触摸选择。

定制入口位于工具面板标题栏关闭按钮左侧，使用铅笔图标与“定制”文字。定制页采用轻量分区：输入框预览保留细边框，四列工具库使用透明背景，底部常驻设置用细分隔线区分；颜色沿用项目主题变量，深色模式提高选中状态对比度。设置区常驻，打开时默认选中模型。定制预览固定显示图标和紧贴图标的小字名称，按钮保持原有尺寸和间距；正式输入框按保存的显示方式绘制，底部设置预览展示当前控件内容和所选显示方式；上栏为空时收起。切换工具只更新底部设置内容；发送按钮保留位置设置区域的空间，能力提示有内容时显示，底部默认留白 16px，设置区没有单独的关闭入口。左右分区保留无障碍名称，拖动时显示放置区域并展开空上栏，放置区域宽度保持稳定。显示及位置按钮至少 44px 高，工具移动和原有权限操作保持独立。

定制页标题栏提供“单栏默认”和“双栏默认”。单栏默认将工具面板入口和模型放在下栏左侧，上下文和附件加号依次放在下栏右侧、发送按钮左边，收起输入区设为隐藏，其余工具收进面板；双栏默认回到初始双栏。两种默认布局均经确认后保存布局和显示方式，发送偏好与草稿保持原值，仍支持逐项调整。

编辑器完成拖动或选择显示方式后立即保存。关闭、返回和 Esc 退出编辑，正在拖动时 Esc 先结束拖动。恢复默认经确认后重置布局和显示方式。鼠标移动超过拖动阈值后直接拖动，触摸长按后拖动、短滑仍用于滚动。支持跨栏、左右对齐、点选分区、方向键排序及跨栏、Shift＋左右对齐、Delete/Backspace 收纳到工具面板。

## 图标

工具栏、工具面板、定制页与权限选项共用 `web/shared/composer-icons.js` 的静态单色 SVG。图形对照 Codex 26.1111.21308（27194）的资源：Skill 为 skills，计划为 lightbulb-rays，目标为 target；请求批准为 hand，自动审核为终端盾牌，完全访问为 shield-exclamation。模型、上下文、定制及收起采用同一图形集的 brain、gauge、pencil 和 chevron。发送、停止、关闭和选中状态使用 SVG。

图标随现有 `/permissions.js` 组合资源加载，沿用公开 URL 与脚本顺序。图形及状态映射集中维护，其他客户端的权限名称、能力与操作保持各自协议语义。

## 职责

- `composer-state.js` 只计算发送动作与能力矩阵，使用普通数据，无 DOM、存储和工具栏依赖。
- `composer-preferences.js` 集中工具定义、配置校验、移动与样式变更和全局偏好存储。配置键为 `bridge-composer-preferences`，包含布局、显示方式与发送偏好。同页订阅和同源 storage 事件同步配置；保存成功后发布状态，写入失败保留已提交配置。
- `composer-ui.js` 提供创建节点、图标、翻译及幂等 DOM 更新，组件直接使用这些展示函数。
- `composer-submit.js` 显式接收原发送、停止、模式和表单节点、配置、实时状态及操作回调，负责动作展示和菜单。提交与停止边界重新读取运行状态与能力。菜单使用独立对话框接入原生返回，按可视视口定位并限制高度。
- `composer-toolbar.js` 组装原有控件、收起、发送控件及编辑器；工具面板首次打开时创建。宿主显式传入主体、提示和运行状态；工具栏将原生控件转换成普通工具描述，包含标签、禁用原因、预览文字和图标状态。常规更新分为工作模式、控件、布局和模式标签同步，重复请求合并到一次微任务；错误提示观察仅负责展开。溢出测量合并到动画帧，提供边缘提示与键盘滚动入口。
- `composer-toolbar-editor.js` 与独立样式在打开定制时并行加载，只接收偏好存储、工具描述查询、占位文案查询与关闭回调，负责选择、预览、位置和样式编辑；读取已保存的不可变配置，直接调用偏好操作。预览按工具 ID 复用按钮；编辑器自行订阅配置和语言，并在销毁时释放订阅。
- `composer-toolbar-drag.js` 与编辑器通过同一公开资源按序加载，负责鼠标和触摸的长按、移动、落点、取消及自动滚动；通过选择、移动和状态回调交付结果。监听器、指针捕获、计时器、动画帧和拖动节点由控制器统一清理。外部配置更新先取消拖动，再采用已保存设置。
- 两套聊天界面保留发送、停止、授权、会话归属、能力与未知结果处理链。草稿保存文本、光标、引用、Skill 和工作模式；发送偏好由共享设置管理。

## 验证

单元测试覆盖配置校验、工具唯一归属与移动边界、发送动作与能力限制、持久化失败和跨窗口事件。浏览器仅保留预设与编辑、鼠标/触摸拖动和取消、双入口模式同步、跨窗口同步、键盘滚动、深色与紧凑布局，以及调用正式提交处理器的隔离发送场景。测试通过合成接口检查发送参数和停止后的草稿保留。

## 键盘与聊天位置

时间线同时观察消息容器与滚动视口的尺寸。键盘弹出、收起和多行草稿改变聊天可见高度时，复用现有锚点恢复：跟随最新消息的会话保持底部，阅读历史的会话保持原消息与偏移。输入区每帧合并测高，时间线仅在实际尺寸变化后恢复阅读位置。草稿内容与光标变化即时保存，同一份快照复用已解析数据并跳过重复写入，跨窗口修改以当前存储值为准。

浏览器回归覆盖 Chromium/WebKit 宽窄视口的缩小、恢复、多行草稿与历史阅读锚点；Android 15 模拟器使用生产时间线和合成消息验证系统键盘弹出与返回收起。
