# Agent Note: 可选完成通知回答预览

Status: implemented

## 问题

Issue #163 需要在任务完成提醒中直接查看回答片段，现有通知只有状态和标题。回复内容也可能被第三方通知服务和锁屏展示，不能默认开启。

## 决策

增加 includeAnswer 布尔设置，默认 false，桌面和 Web 共用配置。仅在 completed 轮次选择已读取的最后一条非 commentary 助手消息，折叠空白，截取 280 字符；没有回答则使用普通完成文案。

复用[投递隔离](../bug-fix/2026-10-28-notification-delivery-isolation.md)，预览在内存按精确 delivery key 关联，发送前重核开关和目标。不额外读取/激活聊天，不写入完成去重账本。手机入箱仍按已有事件规则存通知正文，故界面注明锁屏和第三方可见。

## 备选方案

默认包含全文信息最完整，但扩大披露并增加通知大小，采用显式开关与限长。

发送时额外读取转录能补齐更多预览，但改变通知成本与原生读取边界；仅使用现有快照，缺失时退回通用文案。

## 影响

用户可直接阅读短回答；打开后通知服务和移动入箱会接触片段，关闭不能撤回已送达内容。网关重启后不为补预览重读历史，允许退回通用完成文案。

## 验证

Python 覆盖默认关闭、回答选择、去重和关闭前未发的预览；Node 覆盖显式保存与重开恢复。没有发送真实第三方通知，设备锁屏显示仍待实测。
