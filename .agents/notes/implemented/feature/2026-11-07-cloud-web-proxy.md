# Agent Note: 云账号登录后透传桌面网站

Status: implemented

## Problem

现有云连接仅供手机 App 使用。用户要求在 bridge.waken.cloudns.be:18787 登录同一云账号后直接连接电脑，无需桌面逐浏览器批准，并明确要求网页随桌面版本更新，不在云端复制维护。

## Decision

新增独立的 account-web HTTPS/WSS 通道。云端验证账号、资格、浏览器会话和电脑归属；桌面信任自己已登录服务器对此通道的认证，只向私有回环监听转发白名单请求。此路径的云服务器处理内容明文，手机 Noise、本地 pin 和逐设备批准继续独立。

网页、脚本、样式、字体和预览壳由桌面实时返回；桌面统一适配 /d/{gateway_id} 命名空间，浏览器状态按账号和电脑隔离。云端仅持有登录与电脑选择入口，不导出或部署第二份聊天网页。退出、换账号和到期关闭相关请求，未知写入不重放。

## 记录归属

自动开通 Web 的前提被[桌面网页总开关](2026-11-08-cloud-web-access-switch.md)部分取代：默认关闭，开启后仍免逐浏览器批准；网站透传和手机权限隔离继续保持。

[同账号目录](../../implemented/feature/2026-11-03-account-device-auto-discovery.md)与[桌面批准](../../implemented/feature/2026-11-03-desktop-approved-cloud-pairing.md)部分重叠：新决定只适用于 Web，手机的密钥批准仍有效。[持久中继](../../implemented/architecture/2026-11-05-persistent-relay-v2.md)部分重叠：保留手机 v2，复用有界流控原则。活跃记录中没有应删除或归档的同义提案。

## Alternatives considered

- 浏览器端 Noise 可维持服务器不见明文，但需要浏览器加密接入；用户选择 HTTPS 服务端代理。
- 构建时导出网页资源到服务器可使首页独立于电脑在线，但造成桌面网页更新与云端资源同步；用户明确要求直接透传，因此取消此方案。

## Testing

桌面云 Python 103 项、资源 8 项通过；模块边界通过，仍为原有 22 条例外。Node 1368 项首次运行 1367 通过，图标函数依赖 window 导致隔离 VM 用例失败；改用 globalThis 后该文件与连接作用域共 12 项定向回归通过。错误发送遇已断开 WebSocket 也会安全退役任务，相关 5 项 Python 重新通过。

真实 Go/Python HTTP/WSS 与生产网页在 Chromium/WebKit 宽、窄视口通过登录、图表渲染、HTML 沙箱、PDF 模块加载、两电脑草稿隔离与退出；夹具用合成客户端，不访问真实编码会话。最后四组回归同时通过同电脑多标签存储事件和异电脑事件隔离。资源布局 5 项通过：新增公开静态路径有显式允许列表，两个普通 Python 模块由导入打包而不重复作为数据资源；模块边界再次通过。服务端独立验证 20 MiB 上传下载、SSE、取消、截断、到期、并发限额与未知写入只发送一次。

生产服务于 2026-11-07 部署，2026-11-08 完成本机 Windows 网关更新与真实浏览器验收。替换前核对运行 PID、实例标识和程序路径，通过网关自己的停止接口停机；746 个新包文件逐一校验 SHA-256，旧网关目录和本机数据保留回退副本。更新后网关恢复云连接，账号、配置、通知及配对文件的校验和一致，3 条本机手机配对记录保留。

Edge 使用用户自行登录的现有云账号打开 18787，电脑目录显示 Desktop 可连接；原桌面网页成功显示真实聊天列表，并打开当前运行聊天读取最新内容，全程未增加浏览器批准步骤。公网 HTTPS 证书验证通过，未登录的电脑目录与桌面 API 返回 401，来自 8787 Origin 的 Web 请求返回 403，原 8787 能力接口返回 200。完整操作及源码归属见 [cloud-web.md](../../../../docs/cloud-web.md)。真实手机连接、生产环境发送/审批/文件写入与新发布安装包仍未验收；本次未构建或安装 Android/iOS。

## Consequences

桌面网页成为唯一内容来源，云端只维护账号入口。代价是网站依赖桌面在线及对云服务器的信任，固定资源路径、CSP 和预览需要跨浏览器回归；新增 Web 协议需桌面与服务器共同升级。HTML 图表壳内嵌固定脚本加 nonce，保留沙箱。文件 20 MiB、每浏览器 8 流、每桌面 64 流，大于 1 MiB 传输每浏览器 1 个、每桌面 2 个；扩展文件大小或 WebSocket 终端时须重新评估流控。本机安装验证只覆盖已替换的 Windows 网关；其他电脑仍需升级到包含该通道的版本。
