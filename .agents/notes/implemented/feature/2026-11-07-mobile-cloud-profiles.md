# Agent Note: 现有手机工作台的可选云接入与多配置

Status: implemented

## 问题

官方云目录给手机的是已登记电脑及加密绑定。云端地址不能交给原有 WebView 当作普通网关网址，协议也不分发网页首页。单账号试验还会在追加账号时替换原身份，导致手机难以同时管理多个服务。

## 决策

安卓和 iOS 沿用原生电脑卡片及本网关的 Web 工作台。编译时从同一公开资源清单组装页面。两端共享固定上游版本的 Rust 登录、设备证明、Noise 握手与并发传输。只有手机选中获准的电脑并完成原生授权后才打开该视图的回环入口。入口限制 Host、Origin 和页面随机凭据，云服务端及桌面仍逐次验证绑定。普通直连、SSH 和 DSH Mobile 使用已有边界。

官方及自建方案共用登录表单。官方地址保留在协议模块；自建方案只接受规范 HTTPS 源地址。系统安全存储保存多份配置，以规范服务器和经验证的账号 ID 确定身份，已有单账号资料在读取时迁移。别名按配置及网关 ID 保存。退出先撤销这部手机的登录状态，保留配对身份和别名；删除清除所选配置。操作前展示受影响的电脑，其他账号继续独立。前台目录按需读取，单个服务失败不阻止其他服务返回结果，不为每份配置创建常驻连接。桌面端不为未登录的云配置分配私有监听器，登录和退出共用同一个生命周期入口。

手机按上一次使用的直连地址或云绑定恢复对应工作台，主动返回电脑列表则保留列表。已验证的云绑定再次打开时沿用设备身份并直接建立新的加密连接；授权状态仍由桌面在握手和每次转发时检查。只有经过授权的云设备可以读取当前 Codex 账号的显示摘要，订阅、额度和模型仍由普通账号面板渲染。桌面折叠云设备或离开该设置页即停止轮询设备列表。

iOS 原型曾因模拟器签名缺少自身钥匙串标识而返回 -34018。真实握手还曾触及 544 KiB GCD 调用栈的保护页。网络任务现在在共享 Rust 运行时轮询，安全存储回调回到原调用线程，保留 Android JNI 的线程约束。共享手机壳在文档就绪时先声明原生菜单归属，样式表稍后就绪时再安装规则，避免 iOS 首次进入同时出现两个更多按钮、底部返回入口消失。

## 备选方案

嵌入另一套 Flutter 聊天页面会建立第二套交互和 Agent 功能实现。给直连地址列表增加云服务器域名也无法通过云协议的设备证明和 API 白名单。账号采用单一全局开关会把新登录、退出和删除扩展到其他配置，因此采用独立的配置身份。

## 验证

Mac 上的 8796、iOS 模拟器和临时 Android ARM 模拟器发现同账号电脑并建立设备证明。两端在指定的同一原 Codex 会话各发送一条无工具标记并收到真实回复，在原生记录中各只有一个用户消息和一个助手消息。Android 模拟器断网后原 TCP 连接消失，恢复网络后建立新连接，原草稿与会话保留。仅关闭 Android 测试绑定，服务端确认 disabled，手机卡片禁止再次打开；其余两条授权保留。

iOS 直连隔离 HTTP 夹具和真实云连接均核验首次进入只有一个更多按钮且右下可以返回。原型升级后复用原有登录，已登录状态可添加服务，官方和自建表单按类型显示字段。隔离测试覆盖单账号迁移、同源不同账号和不同源同账号身份、别名作用域、单独删除、监听器按配置启停及两端共用资源装配。安卓设备卡片的改名和恢复原名已经实测；退出和删除两个确认框均核对范围后取消，保留真实账号。第二套真实自建服务和实体手机留待验收。

在 132.2 的 8796 成品上，两端打开只读账号面板均展示真实订阅、额度及可用重置卡数量。iOS 打开了可用模型，冷启动接回同一台云电脑。两端均在设置中切换过界面语言。iOS 设置最初将临时回环地址误列为可移除的电脑，现已区分云设备名称和直连地址。iOS 模拟器确认云聊天中显示设备名和「云服务」，主动返回电脑列表后显示「尚未选择电脑」。安卓 ARM64 模拟器同时保存直连和云配置，分别从对应页面冷启动，两次均恢复至所选来源。英文卡片使用同一排 Rename 和 Manage，两个按钮间隔实测为 8 dp。Mac 实测云设备折叠、展开和再次折叠，成品保留了已登记的授权。

同一安卓模拟器对同一已授权云电脑分别取三次打开，点击至首次可见反馈的中位数从 1.305 秒降至 0.204 秒，至聊天列表从 2.412 秒降至 1.929 秒。旧云原型 APK 为 11.65 MiB，同一旧源码只改用 Rust release 后为 9.18 MiB，再收缩未用的 JVM 字节码后为 6.92 MiB；整合本轮功能后的 ARM64 APK 为 6.94 MiB。

## 影响

首轮范围限于 Codex 原会话。云端白名单和移动传输尚未覆盖 ZCode 会话、终端 WebSocket 及全部附件行为。未接入第三方客户端 UI、厂商云推送或源码开发重载。独立 Android Test 使用单独的包名；Mac 8796 已正常更新到本地签名的 132.2 网关。移动端本轮使用模拟器，真机耗时与不同网络下的结果尚待实测。
