# Agent Note: 购买按钮直达二维码与网页云入口地址

Status: implemented

## Problem

用户希望直接点击“购买官方云服务 30 天激活码（闲鱼）”弹出二维码，现有外链按钮加独立扫码按钮多了一步。网页云访问开关已能授权，却没有显示访问地址；兑换按钮下紧贴分隔线也影响区域层次。

## Decision

购买按钮直接打开独立的二维码模态框，删除第二个扫码按钮和原外链打开目标。按用户补充要求，购买图由服务器 `GET /v1/sponsorship` 下发；桌面通过现有 HTTPS 云请求通路读取，不保存商品链接或本地生成购买图。每次重新打开读取最新图片，弹窗内语言切换不重新请求。支持关闭、Escape、背景点击和读取失败提示，不打开浏览器、不改兑换输入。只接受有界 PNG data URL，限制尺寸并拒绝外部图片 URL。

已确认开启网页访问时，从当前已登录服务器的 capabilities.web_client 读取一次入口地址，只显示有效的精确 HTTPS origin，官方地址和自建地址都由服务器返回。不猜测端口；未启用或读取失败显示可刷新提示。切账号、关开关时清除旧地址并忽略旧请求；语言切换不请求服务器。地址使用可选中复制的只读输入框，附同账号登录提示。兑换区与网页云区域使用留白，不在按钮底部显示横线。

## 记录归属

部分取代[原赞助入口](2026-11-11-official-cloud-sponsor.md)的双按钮／外链交互和本地生成购买图规则，官方云显示范围由原篇继续持有；购买目的地由服务端图片持有。[网页许可总开关](2026-11-08-cloud-web-access-switch.md)继续持有授权边界。本篇只展示地址，不授予或扩大网页权限。检索上述机制未发现重复提案。

## Alternatives considered

原来的独立扫码按钮保留电脑直接访问的路径，但用户明确希望购买按钮直接弹出二维码，因此统一到单一入口。将官方 18787 地址硬编码最简单，但无法反映自建服务器的域名或端口，故读取服务器公布的地址。

## Testing

143 项桌面 Node 定向测试、3 项购买图 Python 回归和 40 项云账号 Python 回归通过。覆盖 HTTPS origin 校验、公共请求不读取或发送账号凭据、服务端图片变化随下次读取生效、拒绝外部 URL／非 PNG／超限图片且无本地回退；网页地址读取失败、显式刷新、切账号／关闭的迟到响应和语言切换不重复请求均有测试。

24 项 Edge Chromium/WebKit × 1280/390 px 浏览器场景通过，检查购买按钮直接弹窗、关闭按钮／Escape／背景关闭、重新打开读取、翻译与草稿保留、地址只读可选中、关闭隐藏、兑换区无横线且保留 24 px 留白。截图已检查。隔离 HTTPS Go 服务使用真实服务端路由下发图片，桌面 Controller 通过临时受信 CA 校验证书后读取，图片字节与服务端资产一致，没有账户凭据或本地生成。

Windows x64 v2.2.0 完整构建存放于 `.local/deliveries/cloud-server-qr-dialog-2026-11-11/`。安装版与 ZIP 完整性、包内源码一致性及独立 Windows 程序烟测通过；包内不再含 sponsor.cjs。打包后的网关 EXE 通过真实 HTTPS 测试接口读取 PNG 和网页地址，两者与服务端输出一致，图片 SHA-256 为 `8eb63e89a18a91bcc3e5e69d8288f9fc6adf80492b1423fbac0522789bfb0aaf`；记录在同目录 `server-delivery-verification.json`。安装包未签名，未替换用户现有安装。

2026-11-11 用户授权部署服务端和上传代码后，桌面功能提交 `62208392` 已推送 origin/main。服务端 `597c8b8` 已上线，打包网关使用正式域名和证书从公网读取购买 PNG，摘要与上述资产完全一致，结果保存为同目录 `production-qr-verification.json`；不需要客户端本地生成或恢复旧链接。

## Consequences

单一购买按钮减少选择，服务端更新图片不依赖桌面升级；代价是打开二维码需要网络与已上线的 `/v1/sponsorship` 接口，旧服务返回 404 时显示加载失败，不回退旧链接。语言切换仅重绘，重新打开才读取新的服务端内容。

地址只是入口提示，不能证明桌面隧道已就绪；仍需同账号登录和已有权限。服务器未公布网页入口时保留明确状态，不显示推测地址。当前页面内按账号／网关隔离地址缓存；手动刷新可以重试不可用状态，重新进入客户端可读取服务器配置变化。
