# Agent Note: 对话分页与过程读取分层

Status: implemented

当前 UI 的分组展示与聚合读取已由[恢复逐条中间过程展示](../simplification/2026-11-19-unfold-native-chat-process.md)取代；下文保留原决定及兼容端点背景。

[同轮过程折叠](../bug-fix/2026-11-19-native-turn-process-disclosure.md)更新了下文的共享 UI 展开规则。分页、游标校验及存储边界继续适用。

## 问题

工具条目占满最近历史页，输入和回答被挤出首屏。外观隐藏只隐藏节点，远程仍收到过程预览。按运行状态自动展开又把原生补充回执误当作运行操作。

## 决策

同一个 Timeline 提供 conversation、process、detail 三种展示读取。对话页保留普通输入、补充、输出、错误和文件汇总；每个 turn 的过程只带稳定入口、原生任务状态与时间。过程目录返回有界元数据，正文沿用单条分片接口。当前审批仍独立来自实时元数据，缓存不提供控制权限。

Codex 展示投影在归一化工具正文前保留原生条目引用，详情读取才解析对应正文与图片；图片仍使用所属 LiveSession 的缓存和授权范围。普通补充前后的过程分别保留稳定入口与原顺序，目录给出进度说明的有界正文，工具正文继续留空。原 IPC/CLI 快照和保存历史加载可能仍取得完整原生内容；本决定不改变原生协议，不承诺原生来源的全部读取成本固定。WSL 和临时侧聊沿相同 Timeline 契约，关闭视图不停止原生任务。

共享 UI 只响应用户展开，不按运行、完成或补充回执自动开合。每层读取有独立取消控制器；收起、切会话和禁用显示会中止读取并忽略迟到响应。进度说明在过程目录直接显示，操作仅展开对应正文和截图，普通长消息仍可分片展开，复制、引用和编辑读取全文。

过程目录与已读正文仅保存在当前组件内存，收起重开复用，不读写共享历史 IndexedDB，避免过程内容驱逐对话缓存。离开会话后再次展开需要重读；这一限制不触发默认过程请求，也不截断历史。既有对话缓存预算和存储体系不在本批修改。

其他 Agent 继续使用原生 detail 和历史游标。每次目录或正文请求都经过原来的启用、绑定、会话归属核验；manager 只留最近 16 个源页的 Timeline 元数据与预览，不留第二份正文。签名定位游标携带作用域、原生页边界和有序内容摘要，元数据被淘汰后可重新读取同一源页；源内容重排时拒绝旧续页，不能恢复旧 epoch 后跳过内容。原生单页超过 100 条对话时先续读该页，再推进原生游标。ZCode 仍只展示原生已加载窗口。

## 备选方案

在完整 timeline 页之外建立 ConversationHistory 缓存可以较少改动原投影，但仍先解析正文再丢弃，又产生第二套游标和缓存；本实现直接扩展已有 Timeline。整段复制旧失败分支会同时带回运行自动开合及补充回执误判，故只复用分层与分页预算。

## 影响与验证

默认远程对话页不含工具正文或截图描述；目录、正文分别受既有字节与字符预算约束。过程内部新增条目不重置对话 epoch；原生对话确实替换仍使游标失效。新 conversation-recent-v1 缓存槽避免升级时把旧混合页中的过程正文挂回首屏，不清空其他会话缓存。

新增回归覆盖千条工具下输入/补充/输出保留、目录与正文独立分页、当前审批保留、更新版本及跨会话游标隔离；6 项共享 manager 测试覆盖淘汰恢复、重排拒绝、240 条对话完整推进和作用域保护。260 项 Node 定向回归、45 项既有桌面接入回归通过。独立复核以 41003 字普通消息确认三页可完整重建，复制、引用、编辑使用同一全文入口。尚未据此宣称真实客户端或手机验收完成。
