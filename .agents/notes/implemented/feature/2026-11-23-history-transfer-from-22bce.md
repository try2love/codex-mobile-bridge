# Agent Note: 基于 22bce233 展示实现历史传输与真实缓存清理

Status: implemented

## 问题

合并后的同步视图给原有聊天增加了独立过程容器，模型文字继承灰色、用时按钮位于步骤下方。用户指定以 22bce233 为实现基线，保留逐步运行、顶部向下展开和现有输入交互，同时补齐按版本同步、完整离线阅读和主动历史传输。原生缓存将正文置空后，SQLite 文件仍保留已分配页，用户在系统储存页面无法观察到清理效果。

## 决策

ChatTimeline 与 DesktopSessions 沿用 22bce233 的消息直接兄弟节点和操作入口。独立的 timeline-sync 数据适配器负责分页、版本与稳定 key 归并，将过程行交给原渲染器。用时按钮置于第一步上方，普通模型正文共用 Markdown 与主题字号。回看锚点、失败展开及首段答复同帧入口由共享回归验证。思考摘要保留独立折叠，原提问定位按钮按后续反馈取消，理由见[摘要与进度入口](../bug-fix/2026-11-23-reasoning-summary-disclosure.md)。

正文复用时的文件引用与分段动作遵循[增量文件操作](../bug-fix/2026-11-23-synced-chat-file-actions.md)，不能因省略正文而丢失在线文件入口。

会话历史通过现有授权入口读取。网关固定原生已保存记录的边界和已连接 owner 的可读取尾回合，将正文与附件按内容版本写入持久清单。正文游标保留源协议的 Unicode scalar 单位，传输分段以字节为单位，完整文本核验使用 UTF-16 长度，避免含 emoji 的原文反复下载。

手机在开始前核对完整正文与已校验分段，记录本次预计下载量。任务按正文、附件、完成核对的顺序读取同一清单。手机时间 requestedAt 用于与实时缓存写入时间比较，网关 capturedAt 标识固定清单，跨设备时钟偏差不会给旧快照更高写入优先级。元数据与任务进度持久保存，取消保留完整内容与已校验分段。

原生存档保存下载分段、引用别名和按清理版本登记的日期范围。清理按原始提问日期删除整回合以及无其他引用的附件和分段，串行收缩数据库并核对实际分配字节。日期范围同时阻止尚未到达的旧清单内容落盘。一次清理影响的回合在任务中跳过，其余回合按新清理版本继续。首次主动打开会话时，先协调手机保留的清理记录，再以当前清理版本补齐首屏；不能因初始化时发现旧清理记录而停在等待「回到最新」。已打开会话中新执行的清理仍取消旧请求，后续按需加载。现有 DisplayStorage 和浏览器回退缓存只清理对应作用域。

冷离线入口加载随 App 打包的同一聊天页面，恢复在线保存的外观设置。原图和附件通过同一预览入口读取已下载字节。同一二进制的多个会话引用保存别名，复用正文时也能定位附件。正常在线图片沿用原内嵌方式，未经重新核验的缓存预览按需读取原件。

二维码复用现有登录授权与过期规则，以固定的 transfer=local 片段打开手机选择页。已有网关缓存命名空间保留部署版 v1 算法，用于现有手机原地升级识别。长期密钥、硬件身份替代方案和配对恢复调研由用户安排的独立路线负责。

原生存档的消息级表、后台转换及首屏与缓存协调分离见[消息级原生历史](../architecture/2026-11-23-message-level-native-history.md)。本篇保留传输、清理与权限边界，该笔记替代整回合 JSON 读取及网络首屏等待原生缓存的实现。

## 备选方案

直接合并原同步路线可以复用全部已实现接口，但它同时改变了过程容器、模型正文和滚动体验。用户选择从 22bce233 新建分支，数据功能逐项接入现有展示组件。前一轮开发状态保存在本地提交 4815d9bd，供具体模块对照。

只清空正文并保留数据库页能减少清理时的写入量，但原生生产存档夹具中，内容已不可读后实际文件占用仍未下降。按用户确认的清理完成语义，当前实现完成物理回收后报告实测释放量。仍被其他回合引用的附件继续保留。

## 影响

固定清单需要网关和手机额外保存清单元数据与未完成分段。准备阶段显式展示计算状态，下载阶段保持单段有界，前台聊天请求独立处理。无法确认完整记录的来源明确报告错误。普通路径和网址保存引用，只有会话保存的文件与原图进入下载。

后台执行遵循系统允许的原生下载时段，系统挂起后在下次打开时恢复任务。受限网络的放行与当前 networkEpoch 关联，路径或计量策略改变后暂停新请求。实际空间不足暂停，已有缓存与分段保留。

## 验证

Chrome 与 WebKit 的窄屏生产 HTTP 合成回归覆盖五种 Agent、旧网关、长过程、首帧用时入口、稳定顺序、阅读位置与上下文用量刷新。Chrome 宽屏验证原输入、引用草稿、实例切换和分屏。任务单元回归覆盖取消保留、受限网络、空间暂停、已清理回合和重开续传。生产网关与实际 Web 任务的合成 HTTP 联调核对分段摘要，重复清单的正文及附件新增请求为零。

生产原生存档夹具核对实际文件占用下降、迟到分段拒收与已完成正文复用。Android API35 现有模拟器验证实际 WebView 的认证分段、冷离线外观、断网锚点及关闭后重开。对应 iOS 源码编译与原生存档夹具通过。安装包与运行版本的最终证据随本次 Test 交付保存在任务本机目录。
