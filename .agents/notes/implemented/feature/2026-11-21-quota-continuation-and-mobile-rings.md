# 2026-11-21 额度恢复后自动继续与手机额度圆环

主页总开关默认关闭，网页、手机 WebView 与桌面 IPC 写入同一个网关设置。额度继续独立于通知通道，仅处理默认配置、官方账号、原生 owner 可读取的本机 Codex Desktop 聊天。

原生明确额度错误即登记等待，不依赖轮询命中零额度；发送前重新核验账号、owner、轮次、目标、归档、待处理请求和个人额度。只读预检临时失败可重试；首次原生写入前落盘不可重放标记，结果未知不自动重放。手动停止按轮次单独持久化，跨重启和开关切换保留。普通失败和其他客户端不触发。

原生 systemError 可作为同步状态读取；默认生命周期空闲核验仍拒绝它。仅额度继续的显式预检在证明原生额度错误且核对预期轮次时允许该状态。主页显示待继续、已继续、结果待确认计数及同步兼容错误。

手机聊天标签右侧显示短期和每周剩余额度圆环，点击展示用量与恢复时间。组件归共享 accounts 功能，通过现有组合资产装配，手机浏览器视口与原生宿主分别判断。仅查询现有认证接口，切换配置清空旧数值并丢弃旧响应，隐藏页面不查询，缺失数据显示破折号。

回归覆盖明确额度识别、手动停止、账号变化、发送前故障、重启防重放、原生状态校验、HTTP 认证/CSRF、跨页设置同步和额度圆环。使用合成状态与只读额度响应，不启动真实模型任务；真实额度耗尽恢复、Android/iOS 真机与其他操作系统仍需验收。
