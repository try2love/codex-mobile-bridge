# Agent Note: 剩余额度作为独立可定制工具

Status: implemented

## 问题

额度与模型入口绑定，无法单独安排位置或隐藏；只查看额度也必须打开完整模型设置。

## 决策

在现有工具注册表加入“剩余额度”，默认紧接模型，沿用四个工具栏分区、工具面板、隐藏与三种显示方式。旧布局在模型之后补入一次新工具，原工具顺序和显示偏好保持；用户已保存的新位置优先。

模型与额度为两个独立容器，额度弹窗只显示额度池、剩余及已用比例、恢复时间、查询更新时间和刷新。模型设置原有额度保留。两者复用 quota-display 展示和宿主的同一份额度状态，模型目录缓存不承担额度缓存，也不覆盖额度更新时间。

Codex 保留既有账号查询与五分钟成功缓存。原生接入按已有模型目录接口读取；只有已提供额度的会话显示可用入口，前台打开详情时每分钟读取缓存，手动刷新才请求更新。身份绑定网关、电脑、客户端、会话、世代与模型目录账号；切换或退出关闭弹窗，迟到结果丢弃。失败保留同作用域成功值与时间并标记未更新，成功响应不再提供额度则清除旧快照。没有百分比不伪造零值，明确零值保留。

## 既有笔记审计

[共享额度展示](2026-11-21-shared-quota-display.md)与[输入区定制工具栏](2026-11-14-custom-composer-toolbars.md)部分重叠，已同步入口与默认布局事实；窗口契约、原生模型归属、发送门禁和工具栏持久化决定继续适用。本改动不扩展自动继续范围。

## 备选方案

继续把额度附在模型按钮中可少一个入口，但无法独立移动和只看额度。复制额度查询与渲染到新工具会形成两份缓存和更新时间，因此只拆展示容器并复用状态及组件。

## 影响

输入区多一个可自行隐藏的工具；额度查询权限、账号来源与发送行为保持现有边界。模型设置与独立详情保留各自的额度池展开状态。升级沿用原本工具栏偏好和会话草稿。

## 验证

浏览器合成接口覆盖 Codex 与原生接入的独立入口、手动刷新、失败保留原值和时间、模型设置保留额度、移动、图标文字模式、隐藏恢复、账号切换关闭及旧布局迁移。Node 回归验证原生能力、模型目录、身份隔离和工具栏配置。完整 Node 前端回归 1,868 项：1,867 通过、1 项平台跳过；Chrome 与 WebKit 宽窄屏共 60 项：58 通过、2 项平台触摸夹具跳过。账号切换迟到响应单独检查通过，300 篇 Note 格式通过。桌面 Test 的构建安装证据另保存在本轮项目临时目录；合成额度不等同于真实上游账号额度联调。
