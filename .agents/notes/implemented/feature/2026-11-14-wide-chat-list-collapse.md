# Agent Note: 宽屏聊天列表折叠

Status: implemented

## 问题

#165 希望平板与桌面宽屏为聊天留出更多空间，同时保留现有会话、草稿和工作台标签。

## 决策

由 ClientNavigation 保存一份聊天列表折叠偏好，Codex 与其他客户端共用控制。仅在既有并排布局超过1100px时收起列表；展开按钮置于列表外，空欢迎页也可恢复。只切换布局class，不调用返回列表、不重建聊天或工作台。折叠后列表不再接受键盘焦点。

## 备选方案

复用返回按钮无需新增控件，但它会清除当前聊天选择；按Agent分别做折叠会重复逻辑且偏好不一致。因此复用共享导航与尺寸层，保持中窄屏现有行为。

## 验证

66项导航、布局与资源检查通过。真实Chrome与WebKit隔离夹具覆盖1440、844、390宽度，Codex/Claude/DSH折叠、恢复、草稿与原状态对象保留、英文标签，2项通过；截图已检查。使用合成会话，不声称是手机真机验证。

## 影响

宽屏增加一个可收起/展开的边缘按钮，偏好随客户端切换保留；窄屏忽略该偏好，变宽后恢复。与现有共享聊天阅读状态笔记部分相关，但不改变导航与滚动恢复语义。
