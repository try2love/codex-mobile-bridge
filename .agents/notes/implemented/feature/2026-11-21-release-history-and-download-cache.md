# Agent Note: 用户选择历史版本并管理下载缓存

Status: implemented

## 问题

只检查某个渠道的最新版本，不能满足用户在正式版和预览版之间来回切换的需要。原来仅允许特定预览版返回 2.2.1；完整包在更新成功后自动删除，也使再次安装同一版本需要重新下载。用户明确选择从 Preview 3 开始保留全部已发布版本的选择权，并自行决定何时删除下载缓存。

## 决策

更新页分别提供日常检查、历史版本与安装包、下载缓存。历史列表按官方 GitHub Releases API 的固定仓库地址分页读取，排除草稿，只显示本机系统与架构对应的 ZIP/DMG、ZIP/EXE 或 DEB/AppImage。列表不按新旧版本截断；每次刷新在主进程生成不可变的安装包记录和不透明 ID，渲染器不能提交任意 URL 或本地路径。历史列表使用官方 HTTPS 及逐跳地址检查，不通过镜像取得未签名的发布元数据。安装包传输可以复用现有镜像路径，结果仍必须符合官方摘要与长度。

选择版本只生成候选，单独下载不执行安装、停止网关或覆盖配置。显式安装使用 `switch-version` 意图，确认框显示当前版本、目标版本与具体安装包；允许较新、较旧及相同版本。后台检查不覆盖当前历史选择。历史选择也不表示后台渠道永久改变。

Mac/Windows 的自动 ZIP 替换继续要求有效发布签名、包摘要、平台架构及目标包中的数据格式。`bridge-data-v1` 相同格式通过凭据可读性门禁后允许双向切换；只有已核验的 2.2.1 可以缺少格式字段。源安装版本必须与已确认操作一致。其他历史包仍可按官方 API 摘要校验下载，但进入明确的手动流程；坏签名、清单与 API 摘要冲突不会静默改走手动安装。DMG/EXE/DEB 交给系统打开，ZIP/AppImage 手动路径定位到文件，不把打开安装器或下载成功说成安装完成。

当前安装包的 `update-version.json` 也必须写入相同的 `dataFormat`，只在签名清单中声明不足以证明本机源格式。五平台共享构建入口写入该字段，成品检查与候选安装验收核对实际落盘内容；遗漏时应在构建检查阶段失败，不能通过放宽运行时校验解决。发布包验收曾发现该字段遗漏并复现源格式拒绝，修订后重新构建全部桌面平台。

手动路径的 `transition.dataFormat` 只标识当前源资料的备份格式，`manualInstall` 不授权自动替换，也不能绕过 Python `prepare` 对目标包的检查。安装前保存当前资料位置并建立有限的配置安全副本；继续使用当前资料，不恢复旧账号、绑定或草稿快照。自动切换保留原事务的实例归属、正常停止、健康确认与失败恢复。只有返回不识别 sidecar 的精确 2.2.1 时才恢复旧客户端设置路径，较新目标保留 sidecar。

完整包保留在原更新缓存目录。每次复用重新验证完整长度与 SHA-256；列表只读取普通文件的版本、平台、架构、格式、大小和时间，不为展示扫描整包摘要。删除只接受严格识别的缓存文件名，原生确认默认取消；确认前后复核目录和整批文件身份，再同步删除选中文件。下载、安装准备、确认与删除使用同一互斥边界，已交给外部安装器的包在当前进程中保留使用状态。未完成的 `download-*` 临时目录仍在启动时清理。

## 备选方案

保留“当前渠道最新版本”和成功后自动清理的行为，能减少界面与磁盘占用，但不能满足用户明确提出的历史切换和缓存保留要求。将所有旧包直接交给自动替换可以统一按钮，却不能证明旧格式、签名和安装结构兼容，因此保留经过验证的自动路径与明确的手动路径。用旧用户目录快照回退会覆盖预览期间新增的账号、绑定和草稿，因此不采用。

## 影响

用户可以提前下载、重复使用缓存并在同格式版本之间双向切换，代价是完整包持续占用磁盘，需用户主动清理。历史目录依赖官方 API 可达；网络失败不使用镜像元数据作为可信摘要来源。打开外部安装器后无法可靠判断其结束，因此当前进程保守保护该缓存；重新启动后可重新选择删除。

较早已安装程序不会被反向补上新版本选择入口。更旧版本可能不识别新功能配置，手动安装明确提示这一边界；安全副本保留在当前私有资料目录，绝不上传发布。

手动选择 2.2.1 安装包也在完整备份落盘后恢复旧客户端设置路径；恢复失败保留已完成的副本，并阻止打开安装器。该手动交接只保证交接时配置已兼容，不能替系统安装器核验完成，也不是覆盖交接后并发设置写入的跨进程事务。

## 验证

源码回归覆盖分页超过 100 条及整页边界、各平台全部格式、无效来源与摘要、坏签名不降级、候选刷新竞态、单独下载不安装、缓存复验与批量删除互斥。Python 隔离事务覆盖正式版到预览版再到正式版、较早预览版、同版本重装、最新配置副本、未知目标格式拒绝和健康失败恢复。界面在宽窄窗口运行实际生产脚本，检查中英切换、无横向溢出及取消操作。成品安装与平台原生行为由发布验收单独记录，不把源码夹具等同于真实设备结果。
