# Agent Note: 本机 CLI 网络检查与恢复使用共享面板

Status: implemented

## 问题

会话菜单原先用一次检查和 `window.confirm` 发起本机 CLI 恢复，只显示最终提示。后端已经提供待闲状态、取消、明确强制预览和未知接续后的保存状态连接，但界面无法在当前面板查看这些真实阶段，也没有完整展示强制影响范围。

## 决策

`SessionMenu` 使用同一个 dialog 的 `cli-network` 子视图显示检查结果，不为每个 Agent 复制恢复界面。`app.js` 的原会话回调只透传现有 `cli-network` 请求，并绑定打开时的 CSRF、列表身份、客户端和当前会话 / 主机选择。检查不激活聊天；入口仅保留本机和已登记本机 Codex home，不提供 SSH 账号恢复。

普通恢复继续使用后端的 `confirmed + generation` 预览确认与自动待闲事务。等待或恢复阶段在面板可见、原身份仍有效时每五秒只读核验相同 `operationId`；未知结果不持续自动重试。取消只有用户点击后提交 `action=cancel`，并以服务端成功回执显示取消。`status`、`cancel` 都指向原操作，不重新发起恢复。

明确强制先请求 `forcePreview`，完整显示后端 `scopeLabel`、已知会话列表及可能未列出的任务影响，再由用户确认。提交保留刚取得的 `generation` 和 `operationId`，包括空值，并生成新的 `requestId`；不使用 `force:true`，不因普通恢复不可用或任务未知而自动强制。无法核验原生进程的预览如实显示原因，保留返回和再检查。

GET 返回 `action=reconnect` 时提供独立保存状态确认，提交新的 `requestId`，不重放旧提供商设置或消息。写入传输结果不明时保留未知提示，强制和重新连接可按本次请求 ID 核验；没有收到普通恢复的操作 ID 时通过重新检查读取后端事务。所有路径均不自动重发原写入。

请求期间只禁用当前动作，关闭和返回始终可用。关闭或返回只停止界面观察，不宣称取消后台事务。响应必须仍属于原 dialog、子视图、上下文和身份；切换会话、主机、客户端、登录或列表身份后的迟到回执不会写入新面板。已提交后台恢复仍由原事务保存真实状态。

## 备选方案

保留弹窗并增加几个提示改动最少，但仍无法持续查看、取消等待或具体核验未知结果。为网络恢复新建一套管理 dialog 可独立布局，却会复制会话身份、返回和移动端菜单行为，因此复用共享 `SessionMenu`。把正常恢复不可用当作强制入口禁用条件能减少按钮，但会屏蔽后端允许用户明确处理的未知任务；强制能力始终由新取得的后端身份预览决定。

## 验证

`tests/cli-network-ui.test.cjs` 执行生产菜单处理器，覆盖待闲和取消、明确强制的完整范围与新请求 ID、保存状态重新连接、传输未知只核验、失败取消不伪成功、身份失效、请求期间关闭 / 返回和迟到写入回执隔离。`tests/session-management-ui.test.cjs` 执行实际 `sessionMenuContext` 回调，核验本机 / 独立 home URL 和精确字段、排除 SSH、CSRF / 列表身份 / 会话 / 主机 / 客户端变化的写前与读后保护。首次两文件 25 项通过；复审补充真实后端仅返回 `connected: true/false` 的即时结果展示，一项增量回归通过。未确认连接不会显示已恢复。

共享菜单改动另跑原生旧版复制兼容 11 项：九项直接通过，两个隔离 VM 夹具缺少标准浏览器 `clearTimeout`；补齐夹具后仅重查这两项通过，不改变原生复制协议。

实际 macOS Ego Chromium 390 / 1280 px、中英四组各 31 项通过，使用生产菜单和合成协议回执，不操作实际客户端或模型。覆盖等待、取消、范围显示、明确确认、未知保存状态、关闭与返回可达、迟到回执不重开面板。目检发现英文强制按钮过长且 danger 文字与主按钮背景对比度不足，只修为既有白字主按钮及简短动作词；重新启动冻结资源的夹具后，仅复核 320 / 390 / 1280 px 英文确认按钮，文字均在按钮内，白字配色明确。等待面板和 320 px 最终强制确认截图均已目检。原生强制退出 / 重新接续能力沿用已有后端验收，本点不把协议夹具或浏览器检查当作已安装 CLI 执行、正式 App 或固定会话验收。

## 影响

用户可以在当前面板查看真实恢复阶段、取消等待或明确确认强制范围，同时保留关闭和返回。新增界面不改变自动待闲、进程核验、home 身份和未知操作不重放规则；CLI 释放分组、历史管理和扫描不在本点范围。关闭后需要重新打开检查结果，界面不会在后台自动升级强制。
