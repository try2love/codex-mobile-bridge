# Agent Note: 独立 Codex 客户端管理与 IDE 退出后的恢复

Status: implemented

## 问题

Issue #106 的配置目录只成为默认 Codex 的子入口，缺少独立管理页面和账号管理。用户要求每个配置在本机管理及远程底部均为独立客户端。VS Code 退出后的原会话另有两种失败：原生包被测试清理误删；原 owner 查询超时阻断主动原生恢复。

## 决策

保留注册表、同一 Bridge、同一账号组件及同一聊天渲染器，以入口 ID 区分客户端，以配置目录隔离认证、账号库、账本、草稿和原生服务。默认入口不再聚合独立配置，WSL 仍保留原有组织。桌面管理和 HTTP 账号操作均明确路由所选入口，未知入口不得回退默认账号。已停用入口仍可独立管理账号，但不接入聊天。

明确的 owner 查询超时允许用户主动请求所选目录的原生 shared app-server；不把超时标记为 owner 缺席。原生 home、会话 ID、provider、cwd 校验和 writer 冲突拒绝继续有效。被动读取不启动服务，其他身份错误仍阻断。

独立配置切换账号复用现有账号事务。此配置原生服务运行时，先读取所有已加载会话、请求、目标和后台任务；只对核验空闲且进程身份匹配的此配置服务发送正常退出，不强杀，不操作默认 Desktop。平台无法提供身份安全的正常退出时明确拒绝，不能修改仍被运行时使用的凭据。

## 备选方案

- 沿用默认 Codex 子入口：改动较少，但不能表达独立账号和管理范围，用户明确否定。
- 为独立配置复制账号与聊天页面：容易实现独立外观，但重复维护共享业务，放弃。
- IPC 超时永久拒绝：避免猜测 owner，却让退出 IDE 的历史无法恢复；主动操作改由原生共享服务裁决 writer。
- 直接运行 daemon stop：官方行为在宽限期后可能强制停止，与不强杀约束不符；使用核验同一进程代际的正常退出。

## 验证

真实 Codex 原生组件中，专用目录首次冷启动成功；账号 A/B 均返回 activeVerified，独立服务正常退出后应用新账号，默认 config.toml 与 auth.json 摘要前后相同。两条用户指定的原 IDE 会话均重连成功，约 10.44 秒（包含 owner 超时）与 1.95 秒，随后取消订阅并记录主动释放。没有重启默认 Codex。

Chrome / WebKit 的宽窄屏独立导航、账号范围和项目选择器共 8 项通过。账号隔离、忙碌保护和锁顺序回归通过。最终安装包及真实 LAN / HTTPS 检查在本地 .tmp/issue106-20261102 记录，不能以源码验证替代安装验证。

当时安装后的 Test 在 LAN / HTTPS 验证了独立客户端、账号和直接入口范围；未覆盖手机分主机聚合及新建后发送。后续用户反馈推翻了完整隔离结论，具体修复与新增证据见[共享客户端外壳](../architecture/2026-11-02-shared-client-shell.md)。两条指定历史重连成功，分别读到 3 轮与 2 轮；取消订阅后被动读取没有重新接入。默认目录约 7.3 秒仍包括一次 owner 查询超时，独立目录约 0.4 秒。

追加的默认目录真实发送仅确认 0.5 秒取得受理回执，未取得模型回复：同一原生后台进程仍使用已无监听的 127.0.0.1:15722 代理，而当前执行环境代理端口为 15937。直接 HTTPS 也超时。该后台进程另有活动会话，因此没有重启或修改其运行环境；只正常停止并释放本次测试请求。不能将原生连接恢复等同于模型上游连通。

新增账号查询触发共享模块已有锁顺序问题：后台探针先取 account.lock 再取 manager.lock，切换原先反向取锁。切换统一使用 account.lock → manager.lock，并加并发回归。正常退出遗留 PID 文件须核对实际进程已消失，不能仅凭文件存在认定运行，也不能在无权限或身份不明时认定空闲。

## 影响

IDE 未保存内容不属于无头恢复；合成模型临时入口须保留已登记运行组件且明确依赖测试服务。Windows 的正常 daemon 退出能力尚待核验，不能借用强制结束。独立运行时仍遵守原生 provider admission，不为恢复覆盖原 provider。

## CLI 的失效代理

手机会话菜单可检查此配置原生进程实际继承的本机代理。当原代理不可达而当前系统代理可达时，先核验全部已加载聊天、后台任务、目标和待处理请求。读状态的专用连接随检查关闭。空闲时才允许正常退出同一代进程，在同一 home 保留提供方与凭据环境、更新代理后重新接入原 ID。原生报出的上游响应流错误与手机到网关的连接分别显示；不会自动补发原消息。

独立真实 daemon 经本地模拟上游验证，进程代际改变后仍读回原聊天、目录和唯一一轮历史，默认配置与凭据摘要一致。用户报告的原配置有三条聊天无法确认空闲，正常阻止了恢复。
