# Agent Note: 鸿蒙原生桥与分记录离线归档

Status: implemented

## 问题

用户要求尝试补齐鸿蒙与 Android/iOS 的功能差异。原实验壳没有原生复制、配置复用、上传下载、离线归档及传输。直接搬运 PR #248 的全套实现会继续沿用不匹配的推送协议和缺少绑定证明的换线；重新复制网页脚本也会造成平台漂移。

## 决策

保持独立实验安装身份，继续复用共享工作台和手机脚本。构建前由 `prepare-harmony.py` 生成脚本与完整离线白名单；生成资产不提交，不包含 Android 专属会话脚本。在线和离线 WebView 分开，浏览本机记录不会销毁在线页面或草稿。离线页只装共用布局、复制和配置桥，不能注入会暂停网关读取的在线离线适配器。

原生 prompt 验证选定 origin/设备前缀、token、当前页面及导航代际；复制、上传和文件导出沿真实点击或系统选择器。异步回复、网络结果和选择器返回重新核验身份与前台状态。网关请求使用 API21 支持的 RCP，明确关闭重定向，不通过不支持的 http.maxRedirects 假装实现凭据边界。

离线账号由原生直接访问 `/api/auth` 的结果绑定 gatewayId/identity，页面声明不能创建可信身份。Cookie 备份放 Asset Store，设备解锁时可用；仅向原地址验证后恢复，退出清除备份。连接入口不把相同设备 ID 当作跨地址证明。型号、系统和真实 bundle 版本只用于显示与已认证后的移动端策略。

RDB 使用 S3 和加密配置，按账号、会话、记录、正文偏移及附件块索引；分页只读小窗口，不把整会话 JSON 作为入口。完整历史通过原生二进制分块、块哈希和完整对象摘要核验，流式解析记录，正文按 UTF-16 偏移写入。网络与长导入不占住数据库串行队列，每次只排入短的记录/块写入，前台读取可以穿插。旧传输不会覆盖更新的实时正文和完成证明，内容相同的附件仍绑定每个逻辑别名。

清理递增 revision，标记日期范围并拒绝迟到写入，保留其他账号和日期；持久化任务保留取消和完成后关闭状态。预取仅前台且无计费 Wi-Fi/以太网；用户允许的蜂窝传输绑定当前网络 epoch。离线正文与过程沿同一分页投影，附件只从已核验本机块读取，不回退网络。退出/过期记录需要设备认证；已撤销或身份不明的记录先重新登录。

当前电脑可主动开启前台任务提醒。系统权限只在点击开启时请求；独立认证的事件流使用绑定摘要、顺序游标和系统事件 ID 去重。首次连接或换流只建立基线，不重放旧提醒；后台或退出取消接收。通知打开当前工作台，不自动发送、停止、授权或重放写入。

## 备选方案

直接采用贡献版省去大量平台适配，但现有服务端没有 Huawei 推送提供方，不能靠改一个 kind 字符串获得后台推送。复制 Android 的跨路线切换也缺原生证明验证，继续保留缺口比放宽认证更合适。

整会话 JSON 的存取接口更简单，但会随长会话增长拖慢首屏和导入；在原生桥中用 base64 反复传整块则增加字符串和数据库写入负担。因此完整传输走原生二进制，阅读走有界记录页；仅离线图片查看按需通过现有页面协议返回块。

## 影响

本篇部分替代[单入口实验网页壳](2026-11-21-harmony-experimental-shell.md)的范围决定，其来源归属、地址边界与实验身份仍有效。同关键词检索仅命中该篇及启动资源恢复笔记；后者讨论资源失败归属，与本篇并行，不改动原结论。

Node 执行生产服务逻辑，真实 SQLite 覆盖长 Unicode 正文、全部过程、日期清理、账号隔离、旧数据与实时数据交错及附件别名；平台接口使用替身验证凭据、网络、通知和文档代际。资源生成检查比较共用源文件字节，并验证离线白名单、MIME 与禁止网络的 CSP。官方 API 按目标 API21 核对。

当前没有 DevEco/SDK，未完成 ArkTS/ArkUI 编译或 HAP、系统 Cookie/加密资产/RDB 加密/选择器/通知权限/键盘实机验收。自动换线、Huawei 后台推送、通知直达指定聊天、普通附件下载暂停续传和 App 内更新仍未对齐，不能宣称完整平台等价。源码能力与真实平台交付分别报告。
