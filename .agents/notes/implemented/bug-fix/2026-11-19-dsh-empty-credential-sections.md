# Agent Note: DSH 空凭据映射兼容

Status: implemented

## 问题

DSH 删除最后一项凭据后可以保存 `refs: {}` 或 `records: {}`。本机读取器只识别块式映射，因而合法的空凭据会阻断账号页及依赖账号身份的会话详情。仅放行读取还不够：账号恢复的字节保留写入器原先也只识别块式 section。

## 决策

凭据子集解析器识别独立空映射 `{}`，但不把它当作后续缩进块的起点；其他流式集合、别名、标签、重复键仍拒绝。账号文档把显式 `null` 或 `~` 的 `refs`、`records` 归一为空映射，不改原始文件。账号恢复只将所选 inline 空 section 展开成块式映射，保留原文件换行方式、其他 section、注释和无关标量字节；回滚继续恢复精确原始字节。

## 备选方案

引入完整 YAML 解析器能支持更多语法，但本次只需要原生已出现的空映射与 null，增加解析面和依赖没有必要。仅修解析、不修写入能恢复会话读取，却仍让合法原生文件无法恢复保存账号，因此读取和所选 section 写入一起适配。把 `[]` 视为空映射会隐藏类型损坏，继续拒绝。

## 影响

账号页面和会话模型身份计算可以读取合法空凭据文件；读取不会重写文件或声称存在登录。所选账号恢复保留现有权限、并发文件身份与回滚保护，不读取真实用户凭据或调用上游。通用 YAML 特性仍不属于支持范围。

## 验证

新增回归先在原实现复现空映射/null 读取与恢复失败。定向用例覆盖 LF/CRLF、空块、空映射及 null，实际账号公开读取与 manager 会话详情、错误类型和嵌套 flow/block 混用拒绝、两种账号 section 的恢复与精确回滚。

DSH 账号、共享 adapter、资料目录与迁移的 102 项非 HTTP 回归通过；模块边界与 268 项笔记格式检查通过。另 14 项已有 manual-plugin HTTP 夹具因执行环境禁止绑定 loopback 而在初始化失败，未计为通过。没有操作真实客户端或上游。
