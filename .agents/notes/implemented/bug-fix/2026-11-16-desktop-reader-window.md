# Agent Note: 最近原生页越过阅读窗口时保留旧内容

Status: implemented

## 问题

非Codex原生客户端的最近分页在短时间新增大量记录后可能与已读窗口不重叠。旧实现将它视为整段替换，用户上翻时会丢失当前位置。

## 决策

读者不在底部且新页声明尚有历史、与当前记录没有交集时，保留当前阅读窗口和游标，暂存最新页；中间内容区展示“有新内容”。读者主动选择后切到最新，不影响已更新的任务状态、审批或草稿。切换聊天清除此临时状态。

## 备选方案

不直接把无交集页与旧记录拼接，因为无法证明中间没有缺页或原生回滚。不用清屏刷新推断删除。正在跟随底部仍沿用原有最新窗口与缓存预算。

## 影响与验证

只修改共享桌面聊天正文区域；没有修改顶部和输入区。Chrome/WebKit宽窄屏、四个共享客户端各注入200条无交集新记录，验证原正文节点与像素锚点保留、按钮可见且主动切最新、草稿保持；另五客户端200工具分页/缓存展开回归一起通过，共12个浏览器项目用例。
