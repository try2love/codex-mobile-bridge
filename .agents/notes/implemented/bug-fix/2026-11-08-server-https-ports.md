# 自有服务器 HTTPS 端口

自有服务器 + SSH 接入接受完整 HTTPS 地址中的有效自定义端口。同一公网 IP 的多个入口分别映射到各电脑独立的 SSH 回环端口。保存、Origin 白名单、SSH 检查和导出的部署说明沿用该地址中的端口。

HTTPS 证书校验、精确 Origin 校验和 SSH 回环监听继续生效。省略端口时使用 443；Cloudflare 与 Tailscale 保持各自端口约束。

新增回归覆盖自定义端口保存、Origin 白名单、部署导出和 SSH 检查端口；非法端口校验沿用已有保存用例。认证与 TLS 使用现有回归覆盖。

各网关使用独立 Cookie 名称区分登录。浏览器按主机向各 HTTPS 端口发送 Cookie，同一主机上的服务保持相互信任。
