# Agent Note: 网关保存栏只显示它能保存的字段

Status: implemented

## 问题

客户端账号编辑器在初次快照后挂入网关设置表单。旧保存栏枚举表单里的所有输入项，并用 DOM ID 作为快照键。多个没有 ID 的账号控件共用一个键，读取不同默认值后就会把“客户端与接入”标记成有修改。该页返回客户端列表后，编辑器仍在隐藏子页里。旧保存操作还可能校验这些由账号接口独立保存的必填项。

## 决策

网关设置只跟踪并校验由“保存配置”提交的控件。标记来自当前值与保存快照的差异，而非输入事件次数。连接增删、连接字段和局域网网卡分别列出。保存栏只显示页面、字段或连接名称；密码、Token 等字段的值不进入提示。点击一项会打开对应页面、客户端和折叠区，并聚焦控件。改回原值或保存后自动清除，提交期间的后续编辑保留。

## 备选方案

在排除列表中加入当前账号编辑器能消除这次误报，但新增独立面板时仍会重现，也无法让人找到真正改动的字段。

## 影响

隔离的桌面页面测试在旧代码复现了动态加载账号控件触发误报。真实 Chromium 渲染器配合模拟后端验证了账号页加载保持干净，从概览回到折叠的 Codex 数据目录并聚焦，恢复原值和保存均清除标记。网关模型、凭据存储及客户端各自的保存接口不需要改动。
