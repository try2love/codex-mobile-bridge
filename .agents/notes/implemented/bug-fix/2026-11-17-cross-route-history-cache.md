# Agent Note: 跨信道复用已读历史

Status: implemented

## 问题

手机从电脑列表改用另一个地址后，IndexedDB 无法跨地址读取；非 Codex 客户端的缓存键还额外包含访问地址。

## 决策

共享 ChatHistoryCache 优先使用手机原生绑定存储，普通浏览器继续使用 IndexedDB。保留认证身份、目标主机、Agent 接入实例和会话键；非 Codex 的网关维度改用已认证 instanceId，信道地址不参与。同一绑定的信道令牌在服务端映射到同一 session，因此认证缓存标识不变。

旧地址 IndexedDB 命中时迁移该页；缓存只存既有清理后的展示快照。过期记录不显示，清除与待写操作串行，并用代次拒绝清除前的排队写入。存储不可用继续原有 IndexedDB/网络路径。

## 备选方案

只去掉缓存键中的地址无法跨越 WebView origin 的物理存储隔离。按电脑名共享容易混淆正式和 Test 网关，因此保留原生绑定隔离与服务端已认证身份。

## 影响与验证

Node 测试覆盖跨页面复用、不同认证及 Agent 隔离、过期删除、按账号命名空间清除及清除期间写入取消。真实 WebView 的两地址测试留在本批验收中；该变更不会给缓存内容恢复实时写权限。
