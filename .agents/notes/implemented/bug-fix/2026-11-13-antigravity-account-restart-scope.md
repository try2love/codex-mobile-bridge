# Agent Note: Antigravity 账号切换只正常重启已核验的单个桌面入口

Status: implemented

## 问题

PR150 的剩余账号提交 `d5c2002d2f101b7f655fffdca04c31b6ffdcb65b` 用 Windows `taskkill /F`、POSIX 超时后的 SIGKILL、Linux 同名 language_server 扫描及 Singleton 文件删除完成退出。其空闲检查依赖可截断、可读失败的历史列表。这样既可能结束其他入口，也可能在未退出完整时改写共享凭据或重复启动。

## 决策

- 在当前主线的独立本地分支保留作者原始提交作为合并父节点；合并时保留已经适配的共享界面、有限 OAuth 快照和系统凭据实现。退出与重启另作本地修复，不恢复原 PR 的强杀、广泛目录快照或凭据轮询。
- 延续[原生接入与快照事务](../feature/2026-11-10-antigravity-native-integration.md)的凭据范围、条件回滚及真实身份显示。只将“应用前必须手动退出”的边界扩展为：显式切换可以正常重启一个已发现、默认启动参数的官方 APP 或 IDE。保存副本仍要求全部入口先退出；全部已停止时应用账号不会主动启动任何程序。
- 平台层按同用户、安装映像、进程代次及父子关系准备退出范围。写者集合必须恰好是选定 GUI 与该来源已核验的原生服务。IDE 内置终端的独立 CLI 即使属于 GUI 子树也不能纳入；`agy` 只在明确为本来源 `--hub` 时可作为 GUI 服务。其他实例、自定义启动参数或无法核验的进程均阻断。
- 客户端层通过同一原生服务的 `GetAllCascadeTrajectories` 获取包括子任务的实时状态。只允许明确 IDLE、无待确认、无后台任务/子任务且网关没有排队消息。历史 SQLite、展示缓存、有限列表和断连回退不授权退出。该私有接口的字段由已安装 App 2.29.1 protobuf 描述符及隔离原生响应核对；不支持此契约的版本保留手动退出入口，不猜测空闲。
- 原生 protobuf JSON 在零轨迹时实际返回 `{}`，省略空 map。仅对身份核验通过、指定 RPC 成功返回的这个确切响应按空集合处理；空 HTTP 响应体、错误对象、分页字段、畸形字段和未知状态仍阻断。数据库返回空列表不具有同等语义。
- 退出只发送一次：macOS AppKit、Windows CloseMainWindow、Linux 绑定代次的 pidfd SIGTERM。最多观察 12 秒；拒绝、残留、新进程或身份变化均先于凭据写入失败。没有强杀、helper 清理、按名称退出或锁文件删除。
- 原有凭据事务继续在写入前后核验全部入口停止、比较前值并读回。只更新三个已知 OAuth token 文件和系统登录项，不复制浏览器存储、插件秘密、草稿、账号索引之外的配置或手机绑定。
- 完成应用后只重新打开本次退出的同一安装，继续使用原数据；启动前再次核验安装未变且无共享登录进程。不猜测 DISPLAY/Wayland/DBus，不执行旁边的 launcher，不设置新实例或新 profile。未确认启动时保留已应用凭据并明确提示，不重复启动，也不盲目覆盖可能已被原生刷新过的凭据。
- 当前账号只由原生身份返回确认；启动请求成功与登录成功分别报告。真实退出后的凭据应用若失败，沿用条件回滚并保留错误或恢复副本，应用保持关闭供用户核对，不以重启掩盖未确认结果。
- 账号轮询和切换统一按账号存储、CLI 的顺序加锁；切换覆盖快照预检到启动结果，避免轮询持有账号锁等待 CLI、切换持有 CLI 锁等待账号锁的死锁。
- 凭据读回一致后视为已应用。后续备份清理失败只保留备份并记录日志；原生身份刷新失败保留已保存账号列表、清空未经确认的当前身份，不阻断本次正常重启。应用前或写入中的错误仍走原条件回滚。

## 备选方案

保留所有手动退出能复用已有安全事务，但不能满足已核验桌面入口的一次显式切换。直接套用 PR 的生命周期对 Linux 使用方便，却扩大退出范围并可能丢草稿，故只保留作者历史及快照设计思路。仅补严格 SQLite 查询容易实现，但不能覆盖尚未落盘的原生任务与审批，因此采用原服务快照。原生启动失败后无条件回滚可表现为“原账号不变”，却可能覆盖已发生的原生凭据刷新，故保留已应用状态并报告待核验。

## 影响

共享账号页面和 API 沿用现有实现，只有切换确认文案说明有界重启范围。收益是退出不扩大范围、未知状态不写入、启动失败不损坏配置；代价是多实例、自定义参数及尚不支持任务契约的版本需要用户先正常退出。

本机无法完成 Antigravity 登录，真实双账号切换及重启后登录有效性没有验收。Windows 正常关窗是否被产品接受、Linux SIGTERM 是否完整保存草稿也未进行本轮实机验证；源码与平台模拟不能代替这些检查。此分支不包含打包、安装、远程推送或正式发布。
