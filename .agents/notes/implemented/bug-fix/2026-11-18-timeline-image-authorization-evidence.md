# Agent Note: 分页图片引用保留原生授权证据

Status: implemented

## 问题

长会话分页的附件脱敏会从投影行移除私有图片路径，随后同一次文件引用构建却又从这些附件读取 ImageView 证据。结果原生 ImageView 的 Markdown 图片被降为 `host-` 文件链接，而原生 artifact 接口只认可原始会话中的图片标识，读取返回 KeyError。重复读取复用已脱敏投影，会持续丢失该证据。

## 决策

Timeline 在更新时把当前投影窗口内的原生 ImageView 路径保存在独立内部索引，包含尚未展开的原生过程项。文件引用仅从返回行对应的索引提取证据，附件仍按原规则移除路径。索引随投影更新整体替换，移除原生项后不保留旧证据。最终 artifact 读取仍重新核验当前原生会话，不把展示缓存当作文件读取授权。

既有资源回归同时发现 SSH 拼装中的新增 Windows 库存导入，修复理由与 POSIX 远端范围记在[SSH 目录决定](../feature/2026-10-18-ssh-cli-model-catalog.md)。相关 CI 夹具同步明确提供已核验配置和 Fast policy、声明 `process_bodies` 参数，并在真实原子 replace 边界注入失败；保留原有账号、模型、懒加载、草稿与落盘失败断言。

## 备选方案

- artifact 接口接受 `host-` 前缀可以消除表面错误，但会混淆宿主机只读链接与会话原生文件授权，不采用。
- 每次轮询扫描整个原生历史可重新发现图片，但破坏分页仅整理当前窗口的成本边界；保留窗口级内部索引。
- 保留附件的原始路径可避免单独索引，但会把私有路径带入公开响应，不采用。

## 影响

旧失败在真实隔离 socket 夹具中复现。定向 238 项通过，新增回归覆盖重复投影复用、过程详情、第一屏直接进入对话投影、路径隐藏及删除后拒绝旧 artifact。原生路径仅在内部索引保留，不扩大模型 Markdown 的文件范围，不激活桌面 owner。

历史记录审计：[共用原生历史图片](../feature/2026-10-29-shared-native-history-images.md)部分重叠，继续保留原生来源、按需读取和删除后拒绝原则；本修复只涉及 Codex 分页文件引用，不替代其他客户端图片注册表。没有被完全吸收或失效的提案。
