# Agent Note: 停用客户端停止后台观测并复用已核验缓存

Status: implemented

## 问题

手机接入的启用门已约束写入和部分通知，但应用状态页仍查询停用客户端的原生连接、CLI 和 SSH 状态。默认 Codex 的通知发现、已有跟随连接和模型定时刷新也未完整遵守此门。原 App 继续运行时，这些读取会持续产生进程、网络和唤醒开销。

Claude CLI 的文件归档能力已按程序身份缓存摘要，却每次重新运行同一程序的 `--version`。托盘每次取得相同状态也重建原生菜单。这些工作可以复用已核验结果，无需减少功能或放宽弱网重试。

## 决策

客户端管理器统一区分本机入口与聚合入口的启用状态。独立配置读取自己的登记状态；默认 Claude 停用不阻止已启用的 WSL Claude。后台状态刷新跳过停用原生适配器；Codex 配置就绪信息复用已有展示快照。明确重新启用时，仅为选中的入口做实时探测，退出、账号切换和写入继续保留原有任务与身份核验，不能使用展示缓存代替。

Codex Bridge 通过同一启用回调约束后台通知发现、SSH 维护、会话跟随及模型刷新。默认入口停用时仅关闭本机及其 SSH 跟随连接，保留原生 App、CLI 执行进程、历史、账本和待处理状态；独立 Codex 入口使用自己的回调，不被默认开关连带停用。已停用入口的旧通知候选和待发送通知均不继续触发观察或投递。已接受的原生任务不被取消，未知写入不重放。

四个客户端的模型目录定时器在执行前检查启用状态，停用后的迟到回调不再请求上游或重新安排刷新。Codex 的原生模型目录、已保存账号目录、API 目录、Skill 后台刷新和账号提醒使用相同启用边界。已验证缓存不清除；显式账号管理与手动刷新仍可执行。停用并不终止一次已经进入上游的读取，也不会关闭维持原 App 或现有 CLI 任务所必需的进程。

Claude 文件归档能力只缓存成功验证的程序版本，键包含平台、规范路径、设备号、inode、大小、修改时间、变更时间和摘要。进程内最多保留八项；失败不缓存，程序替换或核验过程中变化均不能复用。账号与进程/任务安全检查不进入此缓存。SSH 临时工作进程不共享这份进程内缓存。

托盘按运行状态、有效地址、忙状态和状态文案复用菜单；地址变化、操作开始/结束和语言切换仍即时更新。

控制面板收到完整快照后，托盘直接采用其中的运行状态和地址，只保存显示需要的字段。五秒内未收到新快照时，托盘才按原入口读取。已经在途的托盘读取不能盖过更新的窗口结果。启停、配对和账号操作继续执行原有实时检查。空通知关注列表直接返回；本机条目只查本机标题，远程标签沿用按配置文件身份失效的主机缓存。

扫码倒计时和配对状态查询只在窗口可见且存在展开的有效二维码时运行；恢复显示时用实际到期时间刷新。地址从网关快照消失时撤销对应授权并释放条目，已换代的异步回执继续按原规则处理。

## 备选方案

延长所有轮询周期改动少，但会同时延迟已启用入口的状态、通知和重连，仍不能消除对停用客户端的访问，因此保留原有已启用路径的调度规则。停用时直接关闭整个适配器或原生进程可以释放更多资源，却会影响 CLI 任务及 ZCode 私有管道承载的原 App，因此仅撤销可安全停止的观察和刷新。

将全部状态、账号和版本结果统一长时间缓存可以进一步减少请求，但会把退出安全证据、账号身份和展示资料混在一起。因此只复用展示快照及精确程序身份下的静态能力，明确操作继续核验。

## 验证

独立夹具覆盖运行中的 App 停用后连续状态刷新不调用适配器、默认 Codex 停用不触发账号探测、WSL/独立实例边界、模型定时器迟到后不再读取或重新安排、保存目录继续可复用，以及手动重新开启恢复实时探测。真实本机套接字模拟原生 owner，验证停用释放跟随连接后仍能接回同一会话及 provider，不发送模型消息。

Claude 相同程序连续十一次能力检查仅执行一次版本子进程；失败后可以重试，替换程序重新核验。托盘连续十次相同快照不重建菜单，地址、忙状态和语言变化仍刷新。受影响的客户端启停、账号与模型目录、通知、Codex IPC/CLI 和独立入口回归通过；模块边界检查仍为原有二十二项历史例外。

桌面夹具验证窗口连续发布时托盘复用快照、窗口停止发布后恢复读取、迟到结果不覆盖新地址，以及隐藏、过期、地址轮换时配对计时器和授权的生命周期。30 次空列表的配置文件解析从 30 次降至零；测试的 Python 临时分配峰值减少约 6.7 MiB，这是单条读取路径的测试结果，不代表整机常驻内存或十二小时电源的下降幅度。

验证运行于 Mac 的独立测试资料与模拟服务，不启动用户模型任务，不操作 Windows/Linux 验收机。这是源码与针对性行为验证，不是新版安装包的三端实测或长时耗电测量；不能由请求次数减少推导真实节电百分比。

## 影响

停用接入后的常规后台读取减少，缓存与原任务保留；已启用入口继续使用既有读写、通知和重连流程。管理界面仍可查询轻量原生进程清单，公共调度器、持有中的 CLI 协议读取及 ZCode 管道保活不因此销毁。大部分时间使用 Test、且两版启用客户端/通道不同的十二小时电源数值，不能直接作为同负载节电比较；后续应在相同启用配置和手机使用强度下测量成品。
