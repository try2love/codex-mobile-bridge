# Codex 原生生成图的会话预览

Codex 原生历史索引和实时状态使用 `imageGeneration`，rollout 的完成事件使用 `Extension` 与 `image_gen.generation`。文本最终答复可以不包含图片链接。此前历史回退忽略完成事件，原生索引中的生成项也没有转换成附件。

历史回退在同一会话和回合内恢复生成项。完成项的内嵌光栅图复用现有的图片预算、摘要和会话所属校验。聊天回复仅携带预览标识，图片通过已认证的会话预览接口按需读取。`savedPath` 不参与文件授权。生成图片显示在主时间线，遵循现有的工具图片显示设置。离线阅读也在主时间线显示已同步的生成图。
