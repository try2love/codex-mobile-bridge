# Agent Note: Android连接探测页返回电脑列表

Status: implemented

## 问题

#164 的自动重连探测页尚未创建 WebView，handleBack 将它误认成电脑列表，触发双按退出。

## 决策

根据既有 entryProgress 区分探测页，返回调用 home/clear 原路径；复用取消探测、Cookie切换票据和generation，使迟到回调不能重新连接。探测页补回顶部电脑列表入口与更多菜单；无WebView时仅提供电脑列表、通知收件箱、手机设置，不调用Web操作。

## 备选方案

直接退出App不能回到电脑列表，单独创建另一返回流程容易漏掉晚响应取消。因此复用现有home清理逻辑，仅区分探测页与电脑列表。

## 影响

探测期间可以返回或打开手机设置；返回取消当次自动重连，既有账号、地址和手机绑定不变。

## 验证

源码定位确认原故障分支。已使用正式签名Test build63 APK，在既有只读AVD中运行生产Activity与本机延迟HTTP探测：系统Back、顶部返回、更多菜单及手机设置均通过；8次真实socket请求的迟到回调不能重新进入连接页，保存的电脑/地址记录保留。界面截图已检查，模拟器正常退出；未操作真实手机或改动网络鉴权。证据位于`.tmp/model-cache-20261114/android-probe/`。
