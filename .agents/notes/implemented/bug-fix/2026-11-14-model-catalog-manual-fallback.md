# Agent Note: 模型目录失败保留有效缓存与精确手填

Status: implemented

## 问题

Codex 官方目录首次失败会抛出异常，模型设置页隐藏手填；缺少思考强度目录也禁止保存。空目录可能覆盖最近成功的模型缓存。这样目录暂不可读就阻断了原生本来支持的显式模型配置。

## 决策

同一已核验账号与项目身份优先使用现有 ModelStore；刷新失败或空目录保留原成功目录及时间。首次失败返回未就绪目录和已核验身份，不把错误写成成功缓存；身份变化仍拒绝旧结果。

Codex 新建与模型设置保留手填。填写的模型原样提交，未选强度时省略 effort，沿用原生值；已知模型的明确强度限制仍校验。Fast 等额外能力仍需新鲜能力确认，不从目录失败或展示缓存推断权限。页面将目录获取失败作为普通状态说明，保留可编辑控件；实际设置失败继续明确报错。旧网关、账号或聊天的晚结果不能填充当前页面。

## 备选方案

继续要求目录成功才能设置会把可用原生能力错误封锁；回退固定模型会改变用户意图。任意跳过账号身份检查则可能串用其他账号配置。因此只放开目录之外的显式模型输入，并保留原有执行归属与身份校验。

## 验证

首次官方目录失败、原生CLI目录失败和UI禁用均已失败复现。对应回归通过；空目录不覆盖成功缓存/时间、账号隔离检查通过。生产设置路径经本机IPC夹具确认精确模型且无强度字段；没有发起模型回合。37项模型/账号启动UI、30项新建与原生缓存/交接检查通过，新增空目录及IPC路径10项通过。

官方 app-server 的模型为可选字符串、effort为可选覆盖，依据 [turn协议](https://github.com/openai/codex/blob/main/codex-rs/app-server-protocol/src/protocol/v2/turn.rs)。桌面设置仍沿用现有IPC映射，不改provider/owner/cwd。

## 影响

模型目录不可用不再等价于模型配置不可用。手填保留用户值，不保证上游接受未知模型；原生拒绝时原样报告，不自动选择其他模型。Windows/Linux未做本轮真机验证。

## 共享编辑器补充

新建目录首次获取失败仍展示手填控件并保留草稿；未确认账号身份时只允许编辑，不伪造身份提交。后续读取成功保留精确输入。已有聊天刷新期间允许使用同身份的有效缓存，读取失败使用普通状态说明，实际写入失败和账号改变仍明确阻断。验证覆盖首读失败、缓存刷新期间提交、失败保存不自动重放、跨账号晚响应。

## Antigravity 原生映射

APP、CLI、IDE 的模型目录分别按已核验账号复用 ModelStore，目录失败保留原时间与映射。所选来源没有账号时不生成有效身份；其他来源离线不会改变本来源缓存。新建、聊天设置和发送使用同一显示 ID→原生枚举映射，目录保存 nativeModel 并过滤 disabled 条目。允许明确填写 MODEL_ 原生标识，由原生服务判断是否可用；未知显示名称明确报错，禁止映射固定默认模型。原生枚举合同来自本机官方 App/IDE 安装包静态核验，隔离测试覆盖两个不同请求结构，不代表未登录环境能实际调用模型。

## 网关管理页

Antigravity 管理页复用共享 CreationModelPicker，按来源和会话保持目录缓存及手填草稿。目录刷新失败不再清空配置或把整个页面设为不可用；连接/账号/保存结果无法核验时仍阻止写入。精确手填和目录失败回归通过，桌面打包清单同步包含共享脚本。

## ZCode 原生选择

完整 provider/model 按首个斜杠拆分，目录临时失败仍将明确选择提交原生校验；设置省略强度时发送空 thought，使用所选模型的原生默认。新建的 config 与 firstInput.modelSelection 同时保留精确模型，防止原生 config 失败后默认模型继续首条消息。已知强度限制、空闲状态、owner、revision 与日志 epoch 校验保留。原生调用结构13项定向回归通过，拒绝时不重放或替换模型。

## Claude 目录失败

Claude Desktop 新建开放原生 start 已支持的手填模型与强度；设置时目录临时不可读，仍提交明确模型/强度至原生 setter并读取确认结果。原生方法能力、已知强度限制和 Code/Cowork 的默认强度语义保持不变。覆盖两来源目录失败、原样提交、确认失败及默认强度回归。

## 复审：账号变化不能降级目录失败

已复现打开模型页后账号切换、旧状态尚未更新时仍能提交的边界。模型目录身份变化现在使用独立错误码；界面在读取、渲染和提交时核验打开时的账号范围，确认变化必须重开，不能变为普通“可手填”。19项相关UI与9项原生缓存回归通过。

## 复审：AGY 账号与历史边界

账号读取暂失败时保留已读取历史和临时草稿，不把整个详情变成失败；模型写入仍须核验当前账号，即使请求未带目录身份也不绕过。显式 auto、空值或未知名称不会隐式选择默认模型；只有未指定模型的原有调用保留原生默认。针对性回归通过。

## 复审：缓存重开与模型草稿

稳定目录缓存不保存连接能力。新建编辑器恢复缓存时补上已支持的手填控件提示，AGY 不提供独立强度；真实提交仍由后端重新核验账号与能力。管理页同一聊天重新加载、Codex目录刷新保留所填模型和强度，目录条目消失转为精确手填而不选其他模型。缓存失败恢复/跨来源重开9项、模型与草稿39项定向回归通过。
