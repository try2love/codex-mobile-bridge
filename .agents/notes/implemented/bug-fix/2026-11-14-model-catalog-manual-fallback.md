# Agent Note: 模型目录失败保留有效缓存与精确手填

Status: implemented

## 问题

Codex 官方目录首次失败会抛出异常，模型设置页隐藏手填；缺少思考强度目录也禁止保存。空目录可能覆盖最近成功的模型缓存。这样目录暂不可读就阻断了原生本来支持的显式模型配置。

## 决策

同一已核验账号与项目身份优先使用现有 ModelStore；刷新失败或空目录保留原成功目录及时间。首次失败返回未就绪目录和已核验身份，不把错误写成成功缓存；身份变化仍拒绝旧结果。

Codex 新建与模型设置保留手填。填写的模型原样提交，未选强度时省略 effort，沿用原生值；已知模型的明确强度限制仍校验。Fast 等额外能力仍需新鲜能力确认，不从目录失败或展示缓存推断权限。页面将目录获取失败作为普通状态说明，保留可编辑控件；实际设置失败继续明确报错。旧网关、账号或聊天的晚结果不能填充当前页面。

## 备选方案

继续要求目录成功才能设置会把可用原生能力错误封锁；回退固定模型会改变用户意图。任意跳过账号身份检查则可能串用其他账号配置。因此只放开目录之外的显式模型输入，并保留原有执行归属与身份校验。

## 验证

首次官方目录失败、原生CLI目录失败和UI禁用均已失败复现。对应回归通过；空目录不覆盖成功缓存/时间、账号隔离检查通过。生产设置路径经本机IPC夹具确认精确模型且无强度字段；没有发起模型回合。37项模型/账号启动UI、30项新建与原生缓存/交接检查通过，新增空目录及IPC路径10项通过。

官方 app-server 的模型为可选字符串、effort为可选覆盖，依据 [turn协议](https://github.com/openai/codex/blob/main/codex-rs/app-server-protocol/src/protocol/v2/turn.rs)。桌面设置仍沿用现有IPC映射，不改provider/owner/cwd。

## 影响

模型目录不可用不再等价于模型配置不可用。手填保留用户值，不保证上游接受未知模型；原生拒绝时原样报告，不自动选择其他模型。Windows/Linux未做本轮真机验证。
