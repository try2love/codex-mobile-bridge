# Agent Note: 整合原生历史保留与异步有界发布

Status: implemented

## 问题

额度与历史修复分支保留同一连接已观察、并由原生目录确认的连续历史尾部；连接恢复分支为减轻流式复制成本把事件状态裁到两轮。整合后真实新轮次事件会再次移除此前可见的历史，单独运行两侧原测试不能发现这一组合。

## 决策

分页查询最多读取四十条轻量回合目录，仅水合当前轮最近一百个消息项；旧正文只复用同一连接已观察且原生仍确认的连续尾部。事件状态也使用四十轮上限，超限同步裁掉对应修订证据，每轮消息项仍限一百。旧正文复用继续受既有字节预算限制。未读取的消息项、未观察的回合及被截断的缓存均保持历史不完整，不能因随后出现完整新轮次而声称全部已读。

实时事件先更新轮次修订，再进入不立即发布的路径；读取期间的新正文仍优先于较旧快照。快照复制、校验和发送保留在独立发布线程，以二十五毫秒合并更新，原生输出不等待慢订阅者。最后一个观察者离开只释放本地观察，不卸载原执行器。

Windows运行时发现复用平台缓存扫描后，跨平台合成测试必须向该共享扫描器提供同一LOCALAPPDATA环境；不改变产品发现行为来适应旧夹具。浏览器初始化夹具显式把已加载的桌面类放入测试全局作用域，保持生产CSP。真实原生烟测的宿主shell下划线变量含非UTF8字节时会令原生工具任务崩溃；仅在该隔离测试启动时移除该变量，产品环境透传不变。

## 既有记录核对

- [宿主接入与历史连续性](2026-11-21-hosted-codex-desktop.md)：部分重叠，保留原生身份、连续目录补证、读取修订和未知写入规则。
- [连接恢复与有界发布](2026-11-21-desktop-connection-recovery.md)：部分替代其两轮裁剪数量；独立发布、消息项上限、编辑、恢复和执行归属保持。
- [普通启动初始化](../feature/2026-11-22-codex-shared-initialization.md)：初始化、账号管理隔离与中继边界不变。未发现同一历史整合机制的活跃提案，旧共享运行时提案保留独有标签同步缺口。

## 备选方案

保留两轮最省内存和复制成本，但组合回归已复现旧历史立即消失。重新读取所有旧轮正文可补展示，却使大历史重复下载；选择复用经当前原生目录确认的有限已观察尾部。把发布移回原生输出线程可简化状态，但会重新阻塞App回执，因此保留异步合并。

## 验证

新增三项组合回归覆盖事件到达后旧历史保留、旧轮消息项截断不能被误报完整、四十轮及修订证据有界；前两类整合问题先复现后修复。原生4MiB隔离烟测覆盖分页、发送、重连、编辑、中断与审批取消，配置不变且只访问回环合成模型。完整Node与浏览器检查、后端结果及最终成品证据记录在本轮私有交付目录，分别报告，不以源码通过替代安装体验。

## 影响

已观察的可见历史不会在新轮次事件时退回两轮，且保留原生消息和快照发布的容量边界。相较两轮状态，最多保存四十轮增加有界内存和发布复制成本；真实旧正文不会全量重新读取。原生回退、完整快照、连接失效及未知写入仍按既有规则处理。
