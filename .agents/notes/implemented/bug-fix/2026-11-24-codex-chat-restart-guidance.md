# Codex 聊天页提前提示远控准备

Status: implemented

## 问题

新版 Codex 普通启动后，需要由网关重新启动才能加载远控适配器。旧提示在聊天重连失败后才建议重启，也会把临时断线引向同一操作。

## 决策

本机默认 Codex 聊天在加载历史时检查远控状态。仅当同一个默认配置的 Desktop utility host 直接运行 App 包内的 stdio 服务、且进程未加载适配器时提示重启。旧版接入和证据不足的情况沿用重连。可见聊天在重连过程中继续检查。

确认后复用桌面准备接口，在初始化锁内查找已经恢复的连接，任务检查前后都核对主窗口、utility host 与运行时身份。已知运行任务、待审批和未确认写入会阻止退出。任务状态不明时使用现有风险确认。连接就绪后接回原聊天。

展示请求共用一秒内的进程扫描结果，已核验端点优先。准备和重连期间每两秒查询，稳定等待时每五秒查询。聊天接回后停止查询并清除旧提示。

## 验证

定向回归覆盖状态识别、连接已就绪时跳过退出、核验期间证据变化、任务保护、权限以及浏览器确认和取消。macOS 隔离 App 实测验证普通启动的运行时进程关系，并验证独立配置在正常规则下被排除。Windows 使用源码及模拟验证。
