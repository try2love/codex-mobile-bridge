# Agent Note: 凭据不可用时也能完成本地云退出

Status: implemented

## Problem

用户报告退出后云账号仍显示为已配置，并要求更新运行网关。当时 Windows 网关仍加载旧 Python 模块，仅刷新渲染器不能更新该进程。

## Decision

先清除本地账号启用状态，再访问 vault 或服务器；本地写入失败不能报成功。清除 access/refresh/device token，保留当前作用域的桌面密钥。退出只使用捕获的 access token，不消耗或轮换 refresh，不要求先重新登录。

回执分别描述本地完成、远端会话撤销确认和 vault 清理错误。缺少/过期凭据或远端失败不保留本地登录；vault 失败明确提示，不声称秘密已擦除，也不回退明文存储。渲染器直接消费确认的退出回执，清理账号显示与临时表单；未知回执仅用状态读取核实，不重放退出。迟到快照或服务资格不能抹掉完成提示或越过账号边界。直连、账号身份、手机可信 pin 与原编码会话保持各自生命周期。

## Alternatives considered

无；原记录未保存独立备选方案。

## Consequences

本地退出不再依赖有效云凭据或网络；远端撤销和 vault 清理仍可能未确认，界面必须分别呈现。渲染器刷新不能替代旧网关进程加载新模块，退出也不授权或切换编码客户端。

## Testing

2026-11-03 的新 Node/Python 断言先在旧源码上复现失败，修复后 58 项云 Python、1,362 项 Node、76 项 Edge 宽窄合成浏览器回归全部通过，无跳过，边界和空白检查通过。覆盖缺失/拒绝凭据、远端与 vault 失败、本地写失败、未知回执、迟到服务读取和账号变化。

当时按用户授权核对并协作重启本地网关（PID 50148 → 50648），私有状态包含新资格字段，配置和身份保留；没有执行真实登录/退出、兑换、配对、邮件或推送。任务专用 SSH MCP 核对已保存主机指纹，密码未进入文件、仓库或命令行，MCP 配置未改。远端 67 条构建源码与本地清单及运行二进制校验值相符，故未重复部署、重启数据库/代理或重置凭据；健康和证书校验的 HTTPS readiness 通过。这些仅为当日记录，不证明当前部署或设备送达。
