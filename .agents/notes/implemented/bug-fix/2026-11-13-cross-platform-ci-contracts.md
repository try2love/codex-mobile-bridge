# Agent Note: 跨平台发布回归的运行环境边界

Status: implemented

## 问题

共享测试中的 macOS 路径、POSIX 权限、CLI 协议版本和默认编码依赖执行机器，导致同一夹具在 Windows 上改变含义。部分 HTTP、工作区及原生移动端夹具尚未包含当前接口字段。完整回归同时暴露 Python 3.9 的 Future 超时异常类型和跨系统文件 URI 解码差异。

## 决策

夹具明确目标平台、版本与路径，同时保留实际宿主的锁实现；平台专属权限测试只在支持的宿主运行。并发测试通过事件表达必要顺序，发现忙碌任务后允许取消尚未执行的审计。补齐现有接口字段、UTF-8 读取和数据库关闭，不改变产品安全判断。

生产代码捕获 concurrent.futures 提供的超时类型；显式 POSIX 文件 URI 使用与宿主无关的百分号解码，Windows URI 保留原转换路径。

## 备选方案

直接扩大超时、忽略整个失败测试组或放宽产品校验会掩盖回归，因此不采用。纯静态编译不能覆盖 Windows 原生生命周期、打包和升级保留，仍分别通过各平台构建验收。

## 影响

已有拒绝写入、未知结果不重放、任务忙碌阻止退出的断言保持有效。目标平台夹具测试与原生运行测试分别提供证据，不将 macOS 本地通过视为 Windows/Linux 已通过。
