# Agent Note: 整轮用时折叠与过程三级展开

Status: implemented

## 问题

上一版误读参考图，只折叠连续工具，把思考摘要和中间说明留在聊天外层。用户再次提供已结束和运行中的真实参考：结束后输入与最终回答之间只保留用时入口，展开后还能展开工具组及单条详情。

## 决策

两条共享渲染路径以原生 turnId 为优先边界；缺少该字段或使用旧 history 占位标识的历史按普通用户消息分段，避免把不同历史任务的最终回复合并。普通用户补充始终留在外层，同一任务可以在补充前后分成两个过程片段。明确回答卡片的消息沿用 interaction 标记收进过程，不根据文字猜测。最终回复、错误与文件修改结果独立；原生 phase 优先；同一原生任务只保留最后一条 final_answer 作为结果。真实异步问题卡片的提示也可能标为 final_answer，任务继续并出现最终回复后，前面的提示归入过程。旧接入没有 phase 时保留每段最后一条 assistant 为可见结果。

运行中保留说明文字；连续工具与思考摘要共用默认收起的过程组，思考不再切断工具组或独立占据外层。纯思考过程组标为“思考摘要”，展开后每条仍可独立查看；当前末尾执行摘要使用透明度呼吸，已完成、已接受的记录不呼吸，系统减少动态效果时关闭动画。完成时外层自动收起一次，用户重新打开后后续刷新保留。缓存转为实时运行时必须打开外层：运行期没有外层开关，不能保留缓存的关闭状态而隐藏过程。外层只用原生输入/开始及最终回复时间计算用时，没有足够时间证据时显示“执行过程”。Codex 每个分页行携带原生任务开始时间，首屏未加载最初输入时也不会丢失该时间证据。不修改顶部、输入区、原生消息、写入操作和任务状态。

活动摘要与单条详情共用静态 CSS SVG mask 图标，尺寸为 1em，颜色继承现有主题。命令、编辑、读取、搜索、网页、电脑操作、任务清单及思考只依据明确的 kind、tool 或 toolName 精确值选择；不从标题、正文或工具输出猜测。电脑操作只识别现有夹具已确认的 cua_repl.js / mcp__cua_repl__js，DSH 原生 bash 显示终端，wait_agent 保持通用。Codex 与 DSH 仅补传已有短工具标识（toolName 至多 160 字符），不复制正文或传输图片；其它接入缺少明确标识时使用通用图标。图标随现有 /style.css 一次加载，继续使用资源内容哈希、gzip、ETag 及带版本 URL 的 immutable 缓存，不新增图片请求或手机图标库。

本决定替代[正文与连续操作独立展示](2026-11-16-inline-activity-disclosures.md)关于取消外层的部分。原[三级分组](../feature/2026-11-16-shared-activity-groups.md)中的稳定节点与缓存约束继续适用；本轮不把文件结果重新放回过程。

## 原生完成时间与操作摘要

Codex CLI 快照和终止通知中的 `completedAt` 是 Unix 秒，接入层与开始时间一样转换为毫秒；IPC 的 `turnCompletedAtMs` 与保存历史中明确 `task_complete` / `turn_aborted` 事件的时间继续保留原生证据。规范化层输出 `completedAt`，时间线逐行携带 `turnCompletedAt`，即使当前页没有输入或最终回复，也能展示原生用时。完成时间优先于最终回复时间；中断或失败同样结束运行态，整轮自动收起一次。手动重新展开后，晚到回复和重复刷新不会再次关闭；同轮恢复运行后再次结束则重新收起。同轮重启清除旧结束时间，不使用网页时钟补造旧历史用时。

索引历史复用现有 2 MiB 时钟尾读及缓存，在同一次解析中收集可唯一关联到原生轮次的终止事件，不增加历史全扫。只有同线程、唯一轮次、相同终止状态的保存历史时钟才补充实时展示，缺少证据时保留原来的最终回复时间回退。时钟变化走元数据增量，不改变原文版本。

原生 `thread_turns.started_at` 同样是 Unix 秒，索引读取时转换为 `turnStartedAtMs`；空值与零值保持缺失。不能直接把秒值贴上毫秒字段名，否则与 rollout 的 ISO 结束时间合并后会显示数千万分钟，并将输入日期显示为 1970 年。转换按数据来源完成，不根据 App 版本或数值大小猜测单位。SQLite 索引、规范化、时间线及晚到时钟增量有贯通回归，旧 IPC 的毫秒值和 rollout 的 ISO 值保持原义。

文件操作通过 `activityFiles` 携带原生完整路径和单次补丁的增删数，与轮末 `fileSummary` 分开；不从 180 字活动预览估算统计，不重复传补丁正文。共享摘要使用单行省略、文件名下划线及独立增删数，保留原文详情入口；连续操作组使用原生语义图标识别命令与编辑，列表与正文对齐并限高滚动。没有已确认文件变更的失败或进行中记录不声明修改统计。

局部过程分页在原生顺序改变时继续保留已展示成员，防止已展开工具移动到旧分页起点之前后被误移除。其节点和内部阅读位置继续遵循[共享阅读状态](2026-10-30-shared-chat-reading-state.md)约束；历史前插和“加载更早过程”仍沿用原有缓存分页。

## 备选方案

- 只给工具摘要换颜色：无法收起思考与中间说明，已被实际验收否定。
- 按文本识别“允许”“好的”等回复：会隐藏普通补充任务，拒绝。
- 以网页打开时间计算耗时：历史分页与重连会产生错误数字，拒绝。

## 影响

复用原来的工具组、详情缓存和稳定节点。原生消息缺少任务边界时仍有保守分段限制；不将真实历史重放称作真实新任务交互，原生实机、只读历史和合成夹具分别记录验证范围。
