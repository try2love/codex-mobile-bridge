# Agent Note: 整轮用时折叠与过程三级展开

Status: implemented

## 问题

上一版误读参考图，只折叠连续工具，把思考摘要和中间说明留在聊天外层。用户再次提供已结束和运行中的真实参考：结束后输入与最终回答之间只保留用时入口，展开后还能展开工具组及单条详情。

## 决策

两条共享渲染路径以原生 turnId 为优先边界；缺少该字段的历史按普通用户消息分段。普通用户补充始终留在外层，同一任务可以在补充前后分成两个过程片段。明确回答卡片的消息沿用 interaction 标记收进过程，不根据文字猜测。最终回复、错误与文件修改结果独立；原生 phase 优先，旧接入没有 phase 时保留每段最后一条 assistant 为可见结果。

运行中保留说明文字和可展开的思考，工具组默认收起；当前末尾执行摘要使用透明度呼吸，已完成、已接受的记录不呼吸，系统减少动态效果时关闭动画。完成时外层自动收起一次，用户重新打开后后续刷新保留。缓存转为实时运行时必须打开外层：运行期没有外层开关，不能保留缓存的关闭状态而隐藏过程。外层只用原生输入/开始及最终回复时间计算用时，没有足够时间证据时显示“执行过程”。Codex 每个分页行携带原生任务开始时间，首屏未加载最初输入时也不会丢失该时间证据。不修改顶部、输入区、原生消息、写入操作和任务状态。

本决定替代[正文与连续操作独立展示](2026-11-16-inline-activity-disclosures.md)关于取消外层的部分。原[三级分组](../feature/2026-11-16-shared-activity-groups.md)中的稳定节点与缓存约束继续适用；本轮不把文件结果重新放回过程。

## 备选方案

- 只给工具摘要换颜色：无法收起思考与中间说明，已被实际验收否定。
- 按文本识别“允许”“好的”等回复：会隐藏普通补充任务，拒绝。
- 以网页打开时间计算耗时：历史分页与重连会产生错误数字，拒绝。

## 影响

复用原来的工具组、详情缓存和稳定节点。原生消息缺少任务边界时仍有保守分段限制；不将真实历史重放称作真实新任务交互，原生实机、只读历史和合成夹具分别记录验证范围。
