# Agent Note: 手机跨信道展示数据归属

Status: implemented

## 问题

活动页面切信道使用既有传输桥保留页面，但返回电脑列表后选择另一地址会创建新页面。各地址的 localStorage 和 IndexedDB 相互隔离，字号设置因此丢失。

## 决策

Android 与 iOS 使用私有展示存储。目录由原生已验证的电脑身份和绑定根凭据派生，网页只能提供记录键，不能指定目录或绑定。桥沿用随机 token、当前 WebView、主框架/来源及前台校验；磁盘 IO 使用独立串行队列，回执再次核验页面代次。凭据不返回网页、不随缓存传输，缓存不提供操作授权。

外观设置通过共享 mobile-ui 脚本读取与保存；新地址恢复后立即应用，不重载页面。用户已修改设置时不接受迟到的恢复。首次接入可迁移该地址已有外观，读取失败不覆盖原生存储。存储排除系统备份。

## 备选方案

继续依靠活动页面传输切换无需新存储，但不能覆盖从电脑列表重开页面。复制整个 localStorage 会携带无关数据和授权状态，所以只开放产品明确使用的展示记录。

## 影响与验证

共享脚本测试覆盖两个独立地址恢复字号、其他绑定隔离及迟到读取不覆盖用户修改；资源与交接回归通过。旧分支曾完成 Android 全量 Java 源码编译；本次选择性集成只运行源码回归，不编译或安装 App。modal 菜单夹具预置已有存储桥，展示存储初始化由独立夹具覆盖；原生真实跨地址和 iOS 编译仍未在本次集成验证，不能由脚本夹具替代。
