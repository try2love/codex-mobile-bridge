# Agent Note: 外部账号管理下的显式原生连接准备

Status: implemented

## 问题

新版桌面兼容实测中，Magpie 管理的账号使原生连接准备被账号写保护拒绝。该操作仅保存 Bridge 私有启动器并正常重启原 App，不需要覆盖原生认证、提供商或模型配置；桌面按钮与后台入口却共用了账号切换限制。

## 决策

默认桌面的显式原生连接准备允许外部账号管理；保留用户确认、当前进程与配置目录核验、任务审计、未知任务的单独确认、写入回执与正常退出流程。外部管理下的自动准备继续拒绝重启。账号切换、认证恢复、提供商与模型配置覆盖仍使用原有写保护，Web/手机的外部管理限制保持。

这调整了[初始化确认入口](2026-11-12-desktop-initialization-confirmed-retry.md)中桌面按钮对外部管理的限制，与[新版宿主接入](2026-11-21-hosted-codex-desktop.md)复用同一准备事务；不增加另一套启动或账号迁移流程。

## 备选方案

关闭外部管理可以沿用原初始化入口，但同时放开账号切换与配置覆盖，扩大了任务范围。由外部脚本直接写启动器可以绕过入口，却会遗漏既有任务核验与写入回执，因此不采用。

## 影响

本机用户可以明确准备连接，同时继续由 Magpie 持有账号配置。后台自动重启权限没有扩大，旧版接入与非桌面账号操作不改变。

回归先复现显式初始化被拒绝，再验证初始化完成且认证、配置文件字节不变；另验证外部管理仍拒绝未准备状态的自动重启。共享面板覆盖桌面允许原生准备、Web 仍受限制，以及账号切换和恢复继续禁用。
