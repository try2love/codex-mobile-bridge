# Agent Note: 增量历史复用正文时保留文件操作

Status: implemented

## 问题

按版本同步会省略已缓存的正文，文件引用却从这批省略后的行提取。页面清单不保存文件引用，因此重开后正文仍在而文件链接变成普通文字。桌面 Agent 正文分段提取引用缺少消息角色，后半段文件引用被过滤；展开时直接追加 Markdown 还会重复显示前一段。

## 决策

文件引用从本次已鉴权页面索引对应的原投影行提取，覆盖 recent、older、range 和 process。正文及过程仍按版本省略。Codex 图片继续使用当前投影的独立 ImageView 证据，不把宿主机链接提升为原生图片授权。轻量 watch 不返回文件列表。

页面缓存仍不保存文件清单。在线验证返回引用后，Codex 已显示节点刷新正文链接，保留行节点与展开状态。完整正文分段保存其随附文件描述，复用分段时保留文件动作；旧版缺少该字段的分段在首次在线展开时补读一次。设备、会话、版本、清理代次与当前目标校验保持生效，最终文件读取继续走原有鉴权接口。

桌面 Agent 展开正文时合并分段文件引用，替换当前正文而非追加第二份 Markdown。同步适配器同时保留引用，后续刷新不丢失刚读取的文件描述。

## 备选方案

直接持久化整页文件清单可减少元数据传输，但会把旧页面描述当作本次在线引用，无法表达当前源已移除的原生证据；页面仍重新核验，只缓存与完整正文版本绑定的分段描述。每次重传全部正文能沿用原引用提取，却使长历史失去增量传输收益，因此按索引补充引用。

## 影响

条件请求仍返回文件元数据，响应大小随当前页面引用数量增长。缓存预览可以先显示文字，当前验证完成后恢复链接；文件元信息、定位、预览和下载各自继续经过网关验证。

五种 Agent 合成会话覆盖首次打开、缓存重开、过程分页、长正文与分段复用；正文保持 notModified，文件操作保持可用。浏览器使用生产 HTTP 接口和实际 IndexedDB，操作合成项目文件。完整前端回归1887通过、1项平台跳过，132项后端定向检查通过。
