# Agent Note: ZCode 保存历史保留任务编号

Status: implemented

## 问题

真实 ZCode 数据库中的 user 和 assistant 已有 anchor.turnId，但保存历史接口未转出。共享过程展示因而只能把每条用户补充作为新边界。

## 决策

在现有有界 SQLite 查询中同步读取可选的 anchor.turnId，仅将非空字符串转为展示字段 turnId。缺失字段不补造，不改变原历史筛选、权限、附件或回复模型读取。

## 备选方案

- 依靠前端相邻文本推断同任务：有原生编号时没有必要，也会误归类，拒绝。
- 读取整段历史计算边界：会破坏已有分页与缓存边界，不采用。

## 影响

共享组件可以利用已存在的任务归属。此改动只覆盖保存历史的已确认字段；不声称当前不可用的原生实时连接已通过验证。

## 验证

实机只读 SQLite 核验 anchor.turnId；保存历史和附件回归检查字段存在/缺失、分页与原模型元数据。
