# Agent Note: 复用安装清单并补齐 Antigravity 原生发现与添加

Status: implemented

## 问题

网关每次启动和新窗口首次打开客户端页都重新枚举安装，已有 `discovered` 清单没有承担重启后的展示缓存。正常连接状态轮询与安装扫描容易被混为一谈。Antigravity 又只进入自动发现，没有接入共享添加表单；官方新版 CLI 安装在 `.gemini/bin/agy`，IDE 2.6 使用同一程序的 hub 模式，原发现器只接受 `language_server`，会漏掉这一运行形态。

## 决策

安装清单带发现规则版本和非秘密的安装输入，保存在已有 `desktop-sessions/settings.json`。启动时输入相同、规则版本相同且已知程序路径仍存在，复用清单；首次无清单、规则升级、登记路径变化、已知程序消失或用户重新扫描时，重新发现。新窗口先读已有状态，只有明确缺少清单才做首次扫描。关闭网关后的本地管理也优先采用这份有效清单。发现结果不是进程或任务证据，已有两秒/十五秒连接状态刷新、通知与写前实时核验继续工作。

Antigravity 的 App、IDE、CLI 安装放在同一默认 provider 的 `installations` 中。共享 `default-application` 表单可以补录三类官方程序，保存路径按原生产品类型归类，不创建第二套用户资料、账号或执行 owner。启用中的接入先停用才能替换安装位置。App/IDE 使用原有 bundle/product 身份，agy 使用安装器的版本元数据、文件身份与匹配 SHA-512；相同文件身份下缓存摘要核验，程序或元数据变化重新校验。安装或历史存在均不自动授予发送能力。

官方 IDE 2.6 的启动参数为 `agy --hub --hub-port=… --app_data_dir=antigravity --csrf_token=…`。hub 前端端口不作为 Language Server RPC 端口；原程序日志给出独立的原生 HTTP 监听，二进制内嵌说明确认原有 `LanguageServerService` 路径及 CSRF 头。发现器验证该监听属于同用户、同进程世代的官方程序，写入继续在请求前后核验。`app_data_dir=antigravity` 对应 App 资料根，即使展示来源是 IDE，也不能改投独立 IDE 目录。多个候选不能唯一归属时保持不可写。

停用时只使用清单展示，不构造 AGY 会话适配器。启用时没有历史也检查原生服务；聊天列表与管理快照按资料来源合并端点探测，不为每条聊天重复扫描进程。实际发送仍走即时端点核验，不使用展示结果代替。

## 备选方案

延长所有轮询间隔改动少，但会延迟断连、启动和重连反馈，也不能消除每次窗口首屏的安装枚举，因此只缓存安装资料。完全取消启动核验可以进一步减少读取，但会保留失效路径，因此明确的安装输入变化或路径消失仍触发发现。

直接恢复 PR150 的宽松 available 能较快显示发送按钮，但其“找到二进制即就绪”和非来源绑定端点不能证明原 owner 已可控制，因此不采用。按 hub 前端端口猜测新写路由也不采用；复用官方已给出的原生 LS 监听和协议。为 AGY 另造添加弹窗会继续分叉共享管理，所以扩展现有默认程序入口，不开放未验证的独立多配置。

## 影响与验证

隔离夹具覆盖 App、IDE hub 对应的实际 App 资料根、CLI 安装元数据和替换拒绝、错误来源/监听/PID 换代、原生 RPC 路径及写前后核验、三类程序的共享添加、持久清单跨重启复用、手动扫描和程序路径消失。原 AGY 23 项、安装发现 16 项、实例注册与运行时 40 项、生命周期 103 项、桌面控制器 28 项、客户端 UI 76 项及桌面 Node 96 项通过；新增发现夹具 6 项通过。模块边界仍为原有 22 条历史例外。浏览器用已安装 Chrome 和 WebKit，在 1280px 与原桌面最小 820px 窗口检查共享添加、中文/英文、App/CLI 路径保存与管理页跳转，4 项通过；不下载新浏览器。

无登录的真实原生只读验证使用官方 App 2.29.1 的 LS，先由其 `--help` 确认 `gemini_dir` 可为绝对路径、`config_dir` 相对该根。专用进程的 HOME、Gemini 与配置根均位于 `.tmp/agy-native-isolation`；额外 macOS 沙箱先通过专用目录可读、正式用户文件拒读的自检，同时拒绝钥匙串服务、非 loopback 网络及专用目录外写入。该 LS 成功启动，生产 `endpoint` 与 `verify_endpoint` 核对同一原生 PID、映像和 `127.0.0.1` 监听；错误 CSRF 返回 401，`GetUserStatus` 返回 200 且无账号身份。没有登录、发送模型消息、修改正式资料或启动正式 App，专用进程已退出。脱敏回执为 `.tmp/agy-native-isolation/result.json`。此证据证明未登录不妨碍这段发现与只读协议，不能推导真实模型收发、IDE hub 真进程或三系统端到端均已通过。
