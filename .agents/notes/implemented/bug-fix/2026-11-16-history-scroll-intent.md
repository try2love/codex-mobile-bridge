# Agent Note: 历史加载只响应外层阅读意图

Status: implemented

## 问题

折叠使外层节点数减少，原“前11个外层节点”策略把距离顶部数千像素的位置也当作历史边界。

## 决策

历史预加载改按实际顶部距离；工具详情与操作列表的wheel/touch由内层处理，不再触发外层历史页。

不取消正常外层上滑和手动加载入口，不扩大到输入区或页面其他滚动。

## 备选方案

拒绝简单加防抖：它只能降低误请求频率，不能修正请求来源。

## 影响与验证

构造生产ChatTimeline的5项回归在旧实现全部失败，修复后分页14项通过；Chrome/WebKit×宽窄屏实布局验证，距离顶部2000px以上不请求、内层两级滚动不请求、外层边界仍请求。新增合成浏览器检查中曾把展开工具的正常detail懒加载误计作history，已按路由区分而非更改产品规避。
