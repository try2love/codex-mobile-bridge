# Agent Note: 找回密码按钮与密码标签的点击边界

Status: implemented

## Problem

用户报告找回按钮旁的空白也会打开重置。密码行的 label 同时包住按钮和输入框，隐式激活落在第一个可标记控件，即找回按钮。

## Decision

按钮放到 label 外，标题使用普通容器，密码 label 用输入框 ID 显式关联。保留间距、翻译和原生键盘激活；点标签聚焦密码框，行间空白不打开找回或发送账号请求。

## Alternatives considered

无；原记录为明确的标签关联修复，未保存其他方案。

## Consequences

点击与键盘行为使用原生关联，避免扩大找回入口的命中范围；维护布局时必须继续区分按钮、标签和输入框。该改动只需刷新渲染器，无需重启网关或服务端。

## Testing

2026-11-03 的浏览器断言先复现按钮外六像素点击把 login 切到 forgot。合成回环测试覆盖中英文空白、标签、输入、按钮、Enter 和设置表单隔离，不操作用户窗口或账号。36 项定向云 Node、1,363 项完整 Node、78 项 Edge 宽窄浏览器回归通过，无跳过；语法、空白及合成登录截图检查通过。
