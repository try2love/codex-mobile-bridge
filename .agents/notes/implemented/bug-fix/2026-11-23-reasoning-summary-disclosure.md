# Agent Note: 思考摘要保留独立折叠并取消进度定位入口

Status: implemented

## 问题

统一模型正文样式时，两个聊天渲染器把 reasoning 排除在活动行之外，导致思考摘要直接展开为模型消息。用户要求恢复正式版「思考摘要」折叠，并明确取消容易误触的「回到本轮输入」。

## 决策

思考摘要沿用共享活动行，以默认收起的 details/summary 展示「思考摘要」，展开后按既有详情规则读取。普通 commentary 和最终回复继续使用相同模型正文样式。两个渲染器和共享任务状态提示均不提供回到本轮输入按钮，已有回到最新与历史滚动继续保留。

这项决定替代[历史传输实现](../feature/2026-11-23-history-transfer-from-22bce.md)中原有的进度旁输入定位入口，其他逐步过程、完成后向下展开和回看位置规则不变。

## 备选方案

把思考摘要作为普通模型消息能直接复用正文样式，但它并非普通中间输出，会持续占据阅读空间；恢复其原有独立折叠。进度旁定位按钮方便长回合回看，但用户实际使用中容易误触，按最新反馈取消，不另增替代按钮。

## 影响

运行中的工具步骤和普通中间输出仍按顺序显示。摘要必须主动展开，进度提示减少一个点击入口。Chrome 宽窄屏覆盖五种 Agent 的折叠、展开、正文样式和阅读状态；Node 针对性回归通过。
