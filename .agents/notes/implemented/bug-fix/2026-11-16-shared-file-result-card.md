# Agent Note: 文件结果卡片共用

Status: implemented

## 问题

文件结果虽然已从活动组移出，共享桌面渲染器仍把带fileSummary的结果当普通空正文，无法显示文件数量和统计。

## 决策

抽取既有Codex文件结果卡片为共享renderChatFileSummary，两个渲染器复用相同文件数量、增删统计和文件列表。仅原生明确提供fileSummary时渲染，不从工具输出猜汇总。Codex原有定位回调和权限边界保持不变。

## 备选方案

复制一套卡片会再次分化，因此仅移动原有实现。不新增各客户端原生文件统计协议。

## 影响与验证

卡片保持外层独立，不请求patch正文；没有定位回调时路径为文本。原有文件控件6项通过，五客户端生产组件夹具补充实际卡片类型与数量检查，避免只测外层占位高度。
