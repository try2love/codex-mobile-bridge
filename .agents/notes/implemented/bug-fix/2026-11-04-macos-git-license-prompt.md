# Agent Note: 已安装开发工具仍反复弹出 Git 安装提示

Status: implemented

## 问题

本机已经安装 Command Line Tools，但启动 ZCode 或 Codex 后仍弹出“git 命令需要使用命令行开发者工具”。只取消弹窗或重新安装 CLT 不能解决。不同时间的统一日志分别指向 Codex 内置执行器和 ZCode 的本地 host，不能用其中一次归因替代所有后续情况。

## 决策

先核对系统选中的开发者目录与真实失败原因，再处理环境，不改 Bridge 的权限检查或原 App 安装包。当前选中完整 Xcode 26.3；`xcodebuild -version` 可以成功，但执行选中 SDK 下的 `-find git` 明确报未接受 Xcode 与 Apple SDK 许可。独立 CLT 的 Git 可用不代表被系统选中的 Xcode 工具链可用。

用户审阅本机许可路径并明确授权后，通过 Xcode 原生许可界面接受。管理员认证由用户在系统窗口自行完成；工具没有读取或输入密码。没有切换系统开发工具目录，没有重复安装软件。

## 备选方案

给每个调用方强制指定 CLT 路径能暂时避开弹窗，但不能修复其他 App 的系统 Git，也可能改变用户预期的 iOS 编译工具链，因此未采用。修改 ZCode 安装包或放宽私有管道身份校验与本问题无关。直接自动接受许可缺少用户授权，因此先明确确认，再等待系统认证。

## 验证

许可确认前，直接执行选中 Xcode 的 `-sdk ... -find git` 返回退出码 69 和未接受许可提示。完成后，不加临时环境覆盖的 `/usr/bin/git --version` 返回 Git 2.50.1，`xcrun --find git` 返回原 Xcode 26.3 内的 Git，`xcode-select -p` 保持不变。旧安装提示进程已不存在。

## 影响

这是本机开发环境修复，不作为发布产品需要额外安装软件的证据。其它机器出现相同文案仍需重新核对选中目录、许可和安装状态。本次问题与[中文路径进程查询](2026-11-04-macos-process-query-utf8.md)互相独立，不能混用根因。
