# Agent Note: 聊天正文与连续操作独立展示

Status: implemented

用户后续提供完整运行/结束截图，纠正了此前对预览的理解；当前展示以[整轮用时折叠](2026-11-16-task-duration-disclosure.md)为准。以下保留当时决定与局限，不将此前误读写成用户否定三级结构。

## 问题

原有“思考与执行过程”外层把说明段落、思考和操作混为一组，与用户确认的 ChatGPT 参考不符。文件结果也不应被视为中间过程。回归只验证分组存在，不能替代视觉与真实阅读验收。

## 决策

只把连续的显式工具活动与已处理互动收进轻量操作组；思考自身保留详情入口，中间说明、用户补充、最终回答与文件结果都是外层内容。组默认收起，用户展开后保持选择，不因任务完成自动关闭。组内限高滚动，字号和颜色复用现有共享设置；不修改顶部与输入区。

原[三级活动分组](../feature/2026-11-16-shared-activity-groups.md)的统一外层决定被本设计替代；稳定节点、原文详情、缓存与阅读状态约束继续保留。[互动展示标记](2026-11-16-completed-interactions-presentation.md)只改变已回答卡片展示，不影响实时待确认请求。

## 备选方案

- 保留原外层仅更换颜色：无法解决正文被折叠和文件结果归类问题，拒绝。
- 每个客户端各自实现参考样式：会重复并漂移，两个渲染器共用分类、分组、标题和样式。

## 影响

临时预览已由用户确认；生产组件按相同结构实现，审批操作和原生状态仍由原逻辑负责。没有原生耗时证据时不显示推算耗时。原生不同协议的活动类型以适配器数据为准，不从普通用户正文猜测。

## 验证

生产渲染器的五客户端夹具在 Chrome 与 WebKit 的宽屏、390px 窄屏均通过；检查用户补充/最终回答/文件结果独立、已处理互动归组、未完成审批独立、浅深色与10/16/32px字号，以及更新/历史前插后的节点和组内阅读位置。没有将合成夹具记作原生端到端验收。
