# Agent Note: 上滑与过程展开保留阅读位置

Status: implemented

## 问题

用户从底部上滑 36 像素后仍在接近底部的阈值内，两条聊天路径继续标记为跟随最新；正文或过程高度变化时，尺寸回调把页面拉回底部。展开过程摘要也没有先记录阅读意图。

## 决策

明确向上滚动立即退出跟随，不以距离底部较近覆盖此意图。用户点击过程摘要时，在展开前保存过程入口相对视口的位置并退出跟随。既有尺寸回调复用该锚点，原生运行、完成状态不控制展开与收起。

## 备选方案

缩小接近底部阈值可以减少误判，但不能表达明确上滑，也无法处理展开后的尺寸变化。停用尺寸回调会破坏正文流式增长时的正常跟随，因此保留回调，只修正用户意图和展开前锚点。

## 影响与验证

Codex 与共享桌面路径各增加两项调用生产滚动、点击及尺寸恢复回调的最小 DOM 回归，旧代码四项均失败，修复后均通过；265 项相关 Node 回归通过。模拟 DOM 结果不替代安装后的真实滚动检查。本次没有增加自动展开、终态自动收起或子 Agent 能力。
