# Agent Note: DeepSeek 保留原生任务边界供过程展示

Status: implemented

## 问题

真实长历史有 turn/start、turn/end 和 assistant/message.data.turn，但消息投影丢弃这些字段。共享折叠只能按 user 消息分段，无法正确覆盖同一任务中的补充与多段说明。

## 决策

消息保留显式任务编号及同页原生开始/结束时间、终态。以原生 turn/end 的 completed 证据标记最后回答，其余已归属任务的说明标为 commentary。普通用户补充保持 user，注入上下文沿用现有 source.kind 分类。只改变展示元数据，不改变原生请求、事件顺序或已有权限与通知状态。

## 备选方案

- 只使用前端 user 边界：兼容旧记录，但不能准确表达已存在的原生任务，不采用为主要路径。
- 从会话 idle 推算成功：缺乏终态证据，不采用。缺失的原生时间或状态不补造。

## 影响

共享用时折叠能复用已有分页数据。历史截断且不含 turn/start 时只能保留可见的显式任务编号；无原生结束信息时不伪造最终回答标记。

## 验证

真实原生长历史的4组任务开始/结束事件已只读核对；专门回归覆盖同任务补充、最终说明和缺失开始/结束的分页。模型/turn投影与隔离传输回归通过。原生页面验收单独记录。
