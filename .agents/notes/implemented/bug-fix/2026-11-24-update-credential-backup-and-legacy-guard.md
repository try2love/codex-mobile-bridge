# Agent Note: 更新备份包含完整网关凭据并约束旧版切换

Status: implemented

## 问题

macOS 凭据已从系统钥匙串迁移到资料目录，但更新配置快照仍仅覆盖连接索引。只备份索引不能恢复密码；相同的 bridge-data-v1 也不足以证明 Preview 3 及更早版本能读取 CMB1 凭据。

## 决策

配置快照包含主密钥、连接密文、ZCode 链接、当前登录和旧登录密文，沿用私有目录、普通文件、符号链接拒绝、大小限制和摘要清单。正常升级保留当前资料，不从旧快照覆盖账号、手机绑定或草稿。

准备自动替换与手动交接的配置备份均核对目标版本。资料中存在 CMB1 新凭据时，切换到 Preview 3 或更早版本在暂存、停止应用和修改旧设置之前拒绝。只有旧钥匙串索引和旧格式登录时仍可走既有回退流程。不读取真实钥匙串、不自动恢复旧登录，也不删除新资料；手动回退由用户按凭据文档完整备份并恢复兼容凭据。

## 备选方案

仅补备份并保留任意同格式回退，可以维持原选择范围，却会让旧版拿到无法读取的新登录。自动恢复旧钥匙串能减少操作，但可能恢复过期账号并再次触发授权，且新保存的密码没有对应旧条目。因此备份和兼容性判断分别执行，拒绝无法保证可读的旧目标。

## 影响

正常升级获得完整的网关凭据恢复副本；备份同样包含密钥，必须按私有资料保护。已有新凭据时旧版自动切换范围收窄，单独下载安装包不变，手动回退需要明确恢复兼容凭据。

## 验证

隔离合成资料覆盖主密钥和密文成套备份、私有权限、符号链接拒绝、新凭据降级无写入、旧预览切换在读取安装包前拒绝，以及旧系统凭据仍可回退。不会对用户真实资料执行降级或凭据迁移。运行结果由本轮验收日志记录，不代表真实安装器或钥匙串授权验收。
