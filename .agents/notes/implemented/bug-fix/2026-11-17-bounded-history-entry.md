# Agent Note: 移除全量历史入口

Status: implemented

## 问题

手机点击“加载完整历史”会触发无边界历史扩展，长会话可能超出传输和内存预算。

## 决策

删除聊天中部的全量加载按钮及其事件处理，保留现有按页“查看更早内容”和失败重试。兼容旧客户端的后端接口不在本提交改动。

## 备选方案

没有仅隐藏按钮或提高上限；前者仍保留误触入口，后者无法解决无限增长。

## 影响与验证

页面不再包含全量按钮和调用，顶部、输入区无修改。草稿浏览器夹具核验输入、停止事件仍绑定，保留按页历史入口且全量入口不存在；兼容旧客户端的后端接口保留。

本次资源、CLI 访问、会话菜单、Timeline 和启动恢复源码回归 77 项通过；已有 Google Chrome 宽屏和 WebKit 窄屏实际执行草稿与延迟发送回执夹具，2 组通过。没有改动后端接口、编译 App 或使用真实会话。
