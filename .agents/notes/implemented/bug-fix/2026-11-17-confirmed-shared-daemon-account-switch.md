# Agent Note: 已确认的共享 Codex daemon 账号切换

Status: implemented

## 问题

默认 Codex 配置由 Desktop 与 CLI 共用。账号切换在 CLI daemon 存活或状态未知时直接拒绝，导致界面已有的任务确认无法完成切换；无条件退出整个共享服务又会影响其他客户端和任务。

## 决策

仅显式确认的默认配置切换可以请求退出共享 CLI daemon。Desktop 运行时先走既有退出流程，随后重新检查服务；Desktop 未运行时先完成核验再切换。退出前检查网关会话与待处理任务、支持的正常排空协议、daemon 配置目录、全部原生线程及其后台任务/Goal，并在发送一次正常退出信号前复核进程代次。信号派发前持久化代次，退出结果不明时不重发同代信号、不修改账号文件。独立配置继续使用原有 profile 生命周期。

## 备选方案

要求用户离开页面手工退出 CLI 可以保持现有安全边界，但无法完成用户已确认的共享账号切换。未确认时自动停止更方便，却会退出其他客户端共用的服务，因此保留明确确认与完整空闲核验。

## 影响

用户确认后，空闲且身份可核验的共享服务可正常退出并继续切换；活动、未知、代次变化或未确认状态保持失败关闭。正常退出失败不会升级为强制结束。定向单元测试只使用模拟服务，不操作用户 daemon 或账号。
