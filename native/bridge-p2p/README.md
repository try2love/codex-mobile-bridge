# Bridge P2P transport

Application-only integration of EasyTier 2.6.4, pinned to
`8428a89d2dabc94c97d370ec607c6ca142473626`. The mobile copy is generated by
`scripts/sync-p2p-mobile.py`; `source.json` records every shared source digest.

No TUN, VPN service, exit node, subnet routing, packet capture, or data relaying is
enabled. Each ephemeral binding network permits only its desktop's dedicated
Noise TCP port. Bootstrap nodes must permit peer RPC and reject data forwarding.

`wss://<server>/v1/p2p/bootstrap` carries bootstrap RPC through the existing HTTPS
port when cloud firewalls block extra inbound ports. The wrapper verifies TLS
with the platform verifier and feeds a private loopback TCP pipe to EasyTier;
it does not use EasyTier's certificate-unverified WSS connector. P2P payload
still travels directly, and fallback payload uses the existing Bridge relay.

The helper reads one bounded JSON configuration from stdin and exits on EOF.
Never put configuration, credentials or network secrets in arguments or logs.

## Reviewed build adapters

- `vendor/thunk-rs` preserves the supported Rust/MSVC Windows linker. Upstream's
  Windows 7 build adapter downloads legacy linker shims; Bridge requires Windows
  10+ and does not need them.
- `vendor/pnet_datalink` is pnet_datalink 0.35.0 (MIT/Apache-2.0), with a Windows
  backend that enumerates interfaces using IP Helper and returns Unsupported for
  raw channels. This removes the unused Packet.dll/WinPcap runtime dependency.
  Other platform backends retain upstream behavior.
- v2.6.4's mobile launcher unconditionally references TUN/DNS types, so those two
  features are compiled on Android/iOS. Bridge uses `Instance` directly with
  `no_tun=true`, supplies no TUN descriptor, enables no DNS service and requests
  no VPN entitlement. This is a compile compatibility requirement, not a system
  VPN integration.
- `vendor/netdev` retains netdev 0.31.0 (MIT) and supplies Darwin's eight-slot
  `RTAX_MAX` on iOS, where libc does not export that constant. macOS keeps using
  libc's constant. iOS omits optional interface display metadata, whose
  SCNetworkInterface APIs are private on iOS; addresses still use getifaddrs.

## Licenses and corresponding source

Bridge's wrapper is MIT. EasyTier is LGPL-3.0 and remains separately licensed.
Distributions must include its license, the pinned complete source, local build
adapters, dependency lockfile, and the application sources/build instructions
needed to rebuild and relink the combined binary. Mobile release packaging must
publish the corresponding source archive alongside APK/IPA artifacts. Do not
describe the complete linked binary as containing only MIT dependencies.

Build prerequisites: supported Rust, platform C/C++ toolchain and protoc 31.1.
`build_support.py` supplies a checksum-verified Windows protoc; CI installs the
native protobuf compiler on macOS/Linux. Build with `cargo build --locked`.
