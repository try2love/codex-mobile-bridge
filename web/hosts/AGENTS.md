# 宿主适配约束

- 这里处理 browser/iOS/Android 宿主事实与页面呈现，不根据宽度把浏览器认作手机 App。
- 窄屏、横屏、触摸输入和工作台可分屏判断归 `web/layouts/`；不要用 viewport 推断宿主。宿主专属 CSS 可保留原有媒体条件，但不能在这里重定义共享布局断点。
- 原生 UA/class 是可伪造提示，不能作为授权依据或替代原生 token/origin/frame/真实点击校验。
- 原生布局标记可能晚于页面脚本出现，查询必须保持动态，不增加后台轮询。
- 两端共用的注入脚本在 `mobile/shared/web/`，不得重新复制到 Java/Swift 或通过远程地址加载。
- CSS 提取必须保留原级联顺序；更新有序资源清单并验证组合结果与窄/宽布局。
