# 页面布局修改边界

- 先读 `README.md`。`wide/` 是默认两栏结构，`compact/`、`medium/` 是后续尺寸覆盖；保留现有断点和级联顺序。
- 尺寸与宿主独立。这里不得判断 iOS/Android、UA 或 `bridge-mobile`；宿主呈现归 `web/hosts/`，原生行为归 `mobile/`。
- 分屏使用聊天容器的实际宽度，不能直接用整个窗口宽度或设备类型。尺寸变化不得重建会话、清空草稿或重置用户的标签/分屏选择。
- 共享聊天、文件、终端等业务仍在 `web/features/`。功能内部控件的响应式样式跟随功能，不在这里复制整份页面。
- 移动 CSS 规则时同步 `web/assets.json` 的有序源清单，不改变公开 URL、相对资源地址或规则优先级。
- 运行 `tests/layouts.test.cjs` 及资源检查；涉及排布时用隔离浏览器夹具验证竖屏、横屏与宽屏。模拟 UA/class 不代表原生 WebView 已验证。
