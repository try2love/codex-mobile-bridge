# HarmonyOS 实验客户端

这是独立安装身份的实验客户端：扫码或输入完整网关地址，在 ArkWeb 中登录并使用共享工作台。地址列表支持重命名，只保存规范地址，一次性配对片段不写入地址列表。返回电脑列表或查看离线记录会保留工作台 WebView；打开另一地址或重新配对前提示确认。

公网地址仅接受 HTTPS；HTTP 限本机回环、localhost 和私有 IPv4。支持网关根地址及精确 `/d/<32 位设备 ID>` 前缀，页面导航限制在所选 origin 与前缀内。证书错误取消加载。列表移除仅删除地址记录，不注销网关设备或清除 WebView Cookie。

## 已接入的能力

- 共享手机布局、原生复制、语言、字号、主题与输入框配置保存；状态栏随页面颜色调整。网关可识别 App 版本、构建号、设备型号和系统版本。
- 原生系统文件选择上传；同网关附件、图片、工作区文件与诊断下载，显示进度和速率，完成后由用户选择保存位置。凭据请求不跟随重定向，不开放任意 URL 下载。
- 登录 Cookie 由 ArkWeb 管理。已核验的绑定令牌另存入仅设备解锁时可用的 Asset Store；恢复前访问原网关验证，主动退出清除该路线的备份。不会保存账号密码，也不会把不同地址当作同一绑定。
- 加密 RDB 按电脑与登录身份隔离保存记录、正文块和附件，首屏按索引分页读取；完整历史传输使用原生二进制分块、哈希核验、断点复用及持久化任务。联网阅读和导入共用记录层，长内容不拼成整会话 JSON。自动预取限前台、无计费 Wi-Fi/以太网；蜂窝传输须由网页明确确认，确认绑定当前网络。
- “保存的离线记录”使用随 App 打包的完整只读页面，可看已保存正文、中间过程和附件，并可清除该电脑的本机记录。离线页禁止网络回退。已退出或过期账号查看前验证设备屏幕锁；被撤销或身份不明的记录须先用原账号重新连接。
- 当前电脑可单独开启前台任务提醒，首次开启请求系统通知权限；通知游标绑定登录令牌的摘要。首次连接及事件流重置不重放旧提醒，退出或回到后台立即取消接收。点击通知打开当前工作台。

尚未对齐 Android/iOS 的自动换线及跨路线绑定证明、Huawei 后台推送、通知直达指定聊天、原生附件下载暂停/重启后续传和 App 内更新。普通文件下载失败可重新下载；完整历史传输有独立的断点续传。实验 bundle 不与 Android/iOS 的本机数据库互导。

## 构建

先从仓库根目录运行：

```sh
python3 -B scripts/prepare-harmony.py
```

该命令从 `mobile/shared/web/` 生成原生注入资源，并通过既有构建器生成离线资源白名单。生成目录已忽略，不提交；网页或共享脚本变动后需重新生成。不要加入 Android 专用 `mobile-session.js`。

再使用支持项目配置 `6.0.1(21)` SDK 的 DevEco Studio 打开本目录，等待工程同步，选择 `entry/default`，在 IDE 中配置自己的设备签名后构建。仓库不含签名证书、密码或本机路径。当前环境没有 DevEco/SDK，本轮没有安装工具、不提供已构建 HAP。

实验 bundle 为 `io.github.try2love.codexbridge.harmony.experimental`，版本为 `0.1.0-experimental`，不会覆盖其他平台或旧贡献版应用。安装与真实设备扫码、Cookie 持久化、系统返回、键盘、TLS、页面重载行为均待真机验收。

## 验证范围

`npm run test:desktop` 自动发现 `tests/harmony-*.test.cjs`。测试执行生产服务逻辑，使用真实 SQLite 验证分页、长 Unicode 正文、全部过程读取、导入和清理；平台接口用替身覆盖绑定核验、原生网络、通知、令牌/点击/导航代际与资源白名单。

这些检查不等于 ArkTS/ArkUI 编译、HAP 签名或 ArkWeb 设备运行。Cookie/Asset Store 生命周期、RDB 加密与物理回收、屏幕锁、通知权限、系统选择器、键盘和布局均需在具备 SDK 与设备时验收。本目录仍保持实验身份，不能据此宣布与 iOS/Android 全面对齐。
