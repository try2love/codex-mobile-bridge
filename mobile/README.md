# 手机 App 本地预览

电脑继续执行 Codex，手机扫描网关二维码后使用现有聊天界面。支持 Android 和 iPhone；浏览器入口继续保留。

## 连接电脑

1. 启动配套的电脑端 Mobile Preview，设置访问方式并启动网关。电脑需要保持运行和联网。
2. 在「手机通知」中开启「手机 App 通知收件箱」并保存。
3. 手机安装 Bridge Preview，点击「扫码连接电脑」，扫描电脑网关为所选地址生成的登录二维码。也可以粘贴地址，输入网关账号和密码登录。
4. 在要接收提醒的聊天里开启「提醒」。两端的右上角「更多」提供通知收件箱、外观、手机设置和刷新。聊天列表底部保留账号信息与返回电脑列表；进入具体聊天后隐藏底栏，将空间留给消息和输入框。通知页可以清空当前电脑在本机的历史记录，新事件仍会正常出现。

外出访问建议选择电脑端的临时 HTTPS；局域网地址只能在可达电脑的网络中使用。临时 HTTPS 地址更换后，需要在手机重新扫码添加新地址。固定域名示例为 `https://codex.try2love.com`，仅用于演示。

点击聊天中的文件附件后，App 会下载文件并打开系统保存界面。iPhone 可存储到「文件」，Android 可选择下载目录；取消保存不会安装或打开附件。

手机 App 中点击聊天的「复制」或「复制代码」可直接复制到系统剪贴板。iPhone App 内保持固定页面比例，正文大小可在「外观与显示」中调整。

二维码只用于本次登录，不保存在电脑列表中。登录状态由系统 WebView 保存，受网关会话有效期和撤销规则约束。需要清除手机登录时，可在手机设置移除电脑，或在电脑端的「登录设备」撤销相应登录。

## 通知的当前能力

- **Android**：设置中开启任务通知并授予系统通知权限。App 进程存活时每 15 秒检查提醒，后台可能被系统回收，不能保证锁屏实时送达。首次同步只记录已有提醒，不集中弹出历史通知。
- **iPhone**：打开 App 时同步收件箱。此预览尚未接入自有 APNs 远程推送，不能依靠它独立接收锁屏任务通知。
- **锁屏任务提醒**：继续使用网关原有的 Bark、ntfy 或 PushPlus。启用电脑端「通知链接优先打开手机 App」后，支持自定义链接的通道可跳转至已保存的电脑。没有安装 App 或通道不支持时，请关闭此项，保留网页跳转。
- **测试通知**：手机设置中的 10 秒通知测试仅检验本机通知显示，不代表远程任务推送已经接通。

收件箱保留最近 200 条事件，默认不包含聊天标题和正文；沿用电脑网关的聊天提醒与通知隐私设置。

## iPhone 灵动岛与锁屏

需要 iOS 16.2 或更新版本。打开一个聊天，在右上角更多菜单选择「在灵动岛显示此聊天」，即可跟踪这个聊天的执行、等待回应和连接状态。支持灵动岛的机型显示灵动岛，其余兼容机型可使用锁屏实时活动。点击卡片可回到对应聊天；选择「结束灵动岛显示」可关闭。

当前预览只在 App 前台同步聊天状态，进入后台且尚未接入推送时显示最后已知状态及同步时间，不能替代后台实时推送。卡片不显示聊天标题或正文。手机设置中的「预览灵动岛」可查看标注为演示的卡片，不会发送聊天消息或启动电脑任务。

## Android 安装

安装 `dist/mobile-preview/Codex-Mobile-Bridge-Android-0.1.0-preview.9.apk`。支持 Android 8.0 及以上，使用本地预览签名，不通过应用商店分发。相机权限仅供扫码使用，拒绝相机权限后仍可粘贴地址登录。

## 项目工作台

连接配套的电脑端 Mobile Preview，进入一个聊天，点击聊天上方的「＋」，选择「文件」「Git」「终端」「侧边聊天」或「子智能体」。浏览器连接同一个预览网关也可以使用。顶部返回按钮直接回到聊天列表；点击「聊天」标签可回到当前对话。

- 文件来自当前聊天的项目目录；SSH 聊天使用对应服务器上的目录。没有关联项目目录的聊天会提示不可用。
- 点击文件夹进入，点击「‹」返回上一级。「搜索」只查当前目录的文件名，「隐藏文件」可显示点号开头的文件。
- 点击文件可打开独立标签，支持 UTF-8 文本、Markdown 和常见图片。最多同时打开 8 个文件；切回聊天时保留草稿和阅读位置。
- 点击聊天中的图片附件可在当前页面预览，左上角「关闭」返回原聊天；Android 系统返回键也会先关闭图片，保留草稿和阅读位置。
- 文件夹和常见文件类型使用不同图标。PNG、JPG 等默认显示缩略图，可在「设置 → 项目文件 → 显示图片缩略图」关闭；选择仅保存在当前设备。
- 「上传」将文件保存至正在浏览的目录，可调整保存文件名。每个文件最多 20 MB，同名不同内容不会覆盖，可换名再传。
- 文件预览右上角「下载」可保存不超过 20 MB 的文件。超过 512 KB 的文本不展开预览，可下载查看；HTML 和 SVG 作为文本显示。

文件面板支持浏览、预览和传输，暂不提供文件编辑和删除。符号链接和特殊文件暂不开放。项目文件可能包含敏感信息，请仅向可信设备提供网关登录权限。

### Git 面板

进入聊天后点击「＋ → Git」，在「变更」「历史」「分支」间切换。

- **变更**：按未暂存、已暂存、未跟踪和冲突分组。点击文件审阅增删高亮与行号，使用旁边的「＋ / −」暂存或取消暂存；也可批量操作。
- **提交**：先暂存需要提交的内容，再点击「提交」，核对文件清单并填写说明。使用电脑或服务器上已有的 Git 身份、签名和 hooks；未暂存内容保留。提交失败后先刷新确认状态，必要时在电脑处理签名或 hooks。
- **历史**：查看真实父提交关系、分叉与合并、分支和标签。支持当前分支或所有分支，逐步加载最近最多 1,000 条提交。点击提交可查看完整说明、作者、时间、父提交和逐文件差异；合并提交默认与第一父提交比较。
- **分支**：从当前提交创建并切换新分支、切换已有本地分支，或将所选分支合并到当前分支。切换、合并前要求工作区干净；不会自动丢弃或暂存你的修改。
- **冲突**：在电脑上解决冲突后，可回到面板暂存并提交以完成合并；也可以确认后「中止合并」，撤销本次合并中的冲突处理。

项目文件操作按当前聊天目录限制；若聊天目录只是仓库的子目录，提交与分支操作需要回到仓库根目录对应的聊天。SSH 项目在对应服务器执行。仓库在操作期间发生变化时，需要刷新核对后重新操作。

面板不提供远程推送、强制切换、历史重写或丢弃文件。上游领先/落后数量来自本地记录，不会自动 fetch。文本差异上限为每份内容 512 KB、比较前后合计 8,000 行；二进制、非 UTF-8、过大文件和子模块提示在电脑上查看。

## iPhone 安装

1. 用 Xcode 打开 `mobile/ios/BridgePreview.xcodeproj`。
2. 连接并解锁 iPhone，按系统提示信任电脑。在 iPhone 的「设置 → 隐私与安全性」开启开发者模式，完成重启和确认。
3. 在 Xcode 的 BridgePreview 和 BridgeActivity 两个目标的「Signing & Capabilities」中选择自己的开发团队。Apple 账号登录和签名授权在本机完成，不需要把密码发给任何人。
4. 选择已连接的 iPhone 后运行。若 Xcode 提示缺少 iOS 平台或设备支持，先按 Apple 的提示完成所需组件安装。

个人免费签名的有效期和可用设备数受 Apple 限制，到期后需重新通过 Xcode 安装。此预览不提供可通用安装的签名 IPA。

## 本地构建

Android 构建脚本为 `scripts/build-mobile-android.py`，仅使用项目 `.tmp/mobile-tools` 中已准备好的 JDK、SDK 和 ZXing，不安装全局工具。原生地址边界验证运行 `python3 scripts/test-mobile-urls.py`；网关收件箱测试位于 `tests/test_mobile_events.py`。

第三方依赖与许可证见 [NOTICE.md](NOTICE.md)。

## 系统后台推送开发状态

平台接入与网关分发代码见 [推送配置说明](push/README.md)。当前预览没有 APNs／FCM 项目配置，启用入口会明确提示未配置。普通 APK 不包含 Firebase SDK；可选 FCM 工程需要配置自己的 Firebase 项目，不能把源码接入等同于推送已接通。

两端连接后右上角更多提供通知、外观和手机设置；聊天列表底部保留账号信息与返回电脑列表，具体聊天页隐藏底栏。通知页可清空当前电脑在本机的历史记录，新事件仍正常接收。

Git 变更和历史提交详情使用浮动窗口：拖动标题移动，拖动右下角调整大小，顶部按钮可恢复默认大小、最大化或关闭。手机上也可拖动窗口上边缘调整高度。窗口位置和大小在当前聊天的标签之间切换时保留；横竖屏切换会自动限制在可用区域内。


### 终端

在「＋ → 终端」输入命令后点击「执行」。面板显示实际主机、项目目录、输出和退出码，可停止运行或清屏。切换标签、关闭后重新打开终端、刷新页面都会读取同一任务，不会重新执行命令。关闭标签不会停止命令；需要停止时请点击「停止」。

每条命令从当前聊天的项目目录开始，使用当前电脑用户或已有 SSH 登录用户的权限。`cd` 和环境变量只作用于本条命令，需要连续操作时请写在同一条脚本中。当前为非交互式命令终端，不支持 vim、密码输入等需要终端交互的程序。单次最长运行 30 分钟，保留最近 256 Ki 字符输出；网关停止会请求终止任务。使用终端需要启用网关密码保护。

SSH 模式使用电脑已有的 SSH 别名和已信任主机，需要服务器可用的 Python 3。连接异常后请先确认服务器上的实际执行结果，不要直接重复运行有副作用的命令。

### 侧边聊天

进入「＋ → 侧边聊天」，点击「新建侧边聊天」。它继承创建时可读取的主聊天上下文，在独立子标签内讨论；主聊天后续的新消息不会自动合入，正在生成但尚未写入的内容可能不包含。两边访问同一工作目录时，文件变化仍会相互可见。

手机 App、网页和电脑浏览器连接同一个 Bridge 网关后，进入同一主聊天的侧边标签即可继续。离开页面、返回聊天列表不会结束临时聊天。点击「结束聊天」或关闭侧边标签并确认后，将停止运行并清除临时内容，其他设备也无法继续。网关重启或切换模型接入账号后，临时聊天不再保留。

支持文本和图片／文件附件发送、粘贴图片、可关闭的大图预览、流式回复、停止回复，以及命令、文件变更、权限和问题确认。发送结果未确认时不会自动重发。不支持的确认类型可停止本次回复，不会要求转到并不存在的桌面标签。

当前每条主聊天保留一条临时侧边聊天，最多同时保留 8 条。此预览支持网关电脑上的聊天；SSH 远程工作区尚未接入。临时聊天不会进入 Codex 普通历史列表，也不会显示为 Codex 桌面的原生侧边标签。

### 宽屏网页分屏

在电脑浏览器中，将工作台标签拖到右侧提示区，或选中标签后点击加号旁的分屏按钮。左栏固定显示主会话，右栏可切换终端、侧边聊天、文件与 Git 等工具。拖动中间分隔条可调整宽度，两栏保留最小可用宽度；分隔条也支持左右方向键，Home 恢复均分。再次点击分屏按钮可返回单栏。

仅在浏览器宽度至少 1100 像素且会话区域足够宽时显示分屏入口；窄屏网页及手机 App 保持单栏。缩小窗口或切换工具不会清空输入草稿。

### 子智能体

在「＋ → 子智能体」查看当前聊天派生的任务树，点击任务查看最近 10 轮已保存的输入、回复和工具记录。面板可见时每 10 秒更新，支持手动刷新。这里的状态来自已保存记录，不代表实时连接状态；当前不提供新建、向子智能体发消息或停止子智能体的控制。

### 聊天列表刷新

聊天列表停留在顶部时每 15 秒同步一次，返回 App 时也会同步；正在搜索或浏览更早列表时不打断当前位置。手机在列表顶部下拉可立即刷新。需要加载网关更新后的页面代码时，仍使用「更多 → 刷新页面」。


## 本地工作台预览更新

- 侧边聊天有独立的模型和思考程度设置，保存后从下一轮生效。两台手机连接同一网关并打开同一主聊天的侧边标签，可继续同一临时聊天；消息、设置和关闭状态共享。重启网关或结束侧边聊天会清除临时内容。
- 主聊天的 Skill 旁可设置请求批准、帮我批准或完全访问权限，由原桌面会话应用，从下一轮生效。是否可用仍受电脑端版本与策略约束；完全访问需要明确确认。
- 网页工作台、手机菜单支持中英文切换，聊天正文、文件内容与用户命名保持原样。
- Android 与 iOS 可分别扫描并保存多台电脑的网关，首页切换电脑；通知跳转仅打开已保存电脑对应的聊天。

### 前台通知

先在电脑网关开启手机 App 通知收件箱、为聊天开启提醒，再在手机设置开启任务通知并允许系统通知。App 保持前台时，会检查已保存电脑的新任务提醒。点击通知可返回对应电脑和聊天。首次打开、恢复前台或网关事件流重置时不会弹出历史提醒；历史记录仍可在收件箱查看。

**本预览不承诺离开 App、锁屏或被系统终止后的通知送达。** iOS 后台推送需要自己的 Apple 推送签名和服务；Android 可靠后台推送仍需要相应系统服务。Bark／ntfy 可作为电脑端外部提醒通道。灵动岛在 App 不活跃时也可能显示旧状态。以后发布 App 时须保留这项说明。

### 平台验证范围

macOS/Linux 使用登录 shell 的连续 PTY；Windows 10 1809 及以上使用系统 ConPTY 和 COMSPEC shell，无需额外 Python 终端依赖。Windows ConPTY 回归已加入现有 Windows CI 测试矩阵，但本轮本地运行环境是 macOS，未声称完成 Windows/Linux 真机测试。侧边聊天面向各系统本地网关；SSH 远程工作区的侧边聊天仍未接入。

Android APK 用于本地验收；iOS 最新源码尚待重新构建，本机 Xcode 当前缺少可用的 iPhoneOS 构建目标。iPhone 真机通知和排版留待设备测试。本轮没有发布公开版本。
