# 手机 App 本地预览

电脑继续执行 Codex，手机扫描网关二维码后使用现有聊天界面。支持 Android 和 iPhone；浏览器入口继续保留。

## 连接电脑

1. 启动配套的电脑端 Mobile Preview，设置访问方式并启动网关。电脑需要保持运行和联网。
2. 在「手机通知」中开启「手机 App 通知收件箱」并保存。
3. 手机安装 Bridge Preview，点击「扫码连接电脑」，扫描电脑网关为所选地址生成的登录二维码。也可以粘贴地址，输入网关账号和密码登录。
4. 在要接收提醒的聊天里开启「提醒」。两端的右上角「更多」提供通知收件箱、外观、手机设置和刷新。聊天列表底部保留账号信息与返回电脑列表；进入具体聊天后隐藏底栏，将空间留给消息和输入框。通知页可以清空当前电脑在本机的历史记录，新事件仍会正常出现。

外出访问建议选择电脑端的临时 HTTPS；局域网地址只能在可达电脑的网络中使用。临时 HTTPS 地址更换后，需要在手机重新扫码添加新地址。固定域名示例为 `https://codex.try2love.com`，仅用于演示。

点击聊天中的文件附件后，App 会下载文件并打开系统保存界面。iPhone 可存储到「文件」，Android 可选择下载目录；取消保存不会安装或打开附件。

手机 App 中点击聊天的「复制」或「复制代码」可直接复制到系统剪贴板。iPhone App 内保持固定页面比例，正文大小可在「外观与显示」中调整。

二维码只用于本次登录，不保存在电脑列表中。登录状态由系统 WebView 保存，受网关会话有效期和撤销规则约束。需要清除手机登录时，可在手机设置移除电脑，或在电脑端的「登录设备」撤销相应登录。

## 通知的当前能力

- **Android**：设置中开启任务通知并授予系统通知权限。App 进程存活时每 15 秒检查提醒，后台可能被系统回收，不能保证锁屏实时送达。首次同步只记录已有提醒，不集中弹出历史通知。
- **iPhone**：打开 App 时同步收件箱。此预览尚未接入自有 APNs 远程推送，不能依靠它独立接收锁屏任务通知。
- **锁屏任务提醒**：继续使用网关原有的 Bark、ntfy 或 PushPlus。启用电脑端「通知链接优先打开手机 App」后，支持自定义链接的通道可跳转至已保存的电脑。没有安装 App 或通道不支持时，请关闭此项，保留网页跳转。
- **测试通知**：手机设置中的 10 秒通知测试仅检验本机通知显示，不代表远程任务推送已经接通。

收件箱保留最近 200 条事件，默认不包含聊天标题和正文；沿用电脑网关的聊天提醒与通知隐私设置。

## iPhone 灵动岛与锁屏

需要 iOS 16.2 或更新版本。打开一个聊天，在右上角更多菜单选择「在灵动岛显示此聊天」，即可跟踪这个聊天的执行、等待回应和连接状态。支持灵动岛的机型显示灵动岛，其余兼容机型可使用锁屏实时活动。点击卡片可回到对应聊天；选择「结束灵动岛显示」可关闭。

当前预览只在 App 前台同步聊天状态，进入后台且尚未接入推送时显示最后已知状态及同步时间，不能替代后台实时推送。卡片不显示聊天标题或正文。手机设置中的「预览灵动岛」可查看标注为演示的卡片，不会发送聊天消息或启动电脑任务。

## Android 安装

安装 `dist/mobile-preview/Codex-Mobile-Bridge-Android-0.1.0-preview.8.apk`。支持 Android 8.0 及以上，使用本地预览签名，不通过应用商店分发。相机权限仅供扫码使用，拒绝相机权限后仍可粘贴地址登录。

## 项目工作台

连接配套的电脑端 Mobile Preview，进入一个聊天，点击聊天上方的「＋」，选择「文件」或「Git」。浏览器连接同一个预览网关也可以使用。顶部返回按钮直接回到聊天列表；点击「聊天」标签可回到当前对话。

- 文件来自当前聊天的项目目录；SSH 聊天使用对应服务器上的目录。没有关联项目目录的聊天会提示不可用。
- 点击文件夹进入，点击「‹」返回上一级。「搜索」只查当前目录的文件名，「隐藏文件」可显示点号开头的文件。
- 点击文件可打开独立标签，支持 UTF-8 文本、Markdown 和常见图片。最多同时打开 8 个文件；切回聊天时保留草稿和阅读位置。
- 点击聊天中的图片附件可在当前页面预览，左上角「关闭」返回原聊天；Android 系统返回键也会先关闭图片，保留草稿和阅读位置。
- 文件夹和常见文件类型使用不同图标。PNG、JPG 等默认显示缩略图，可在「设置 → 项目文件 → 显示图片缩略图」关闭；选择仅保存在当前设备。
- 「上传」将文件保存至正在浏览的目录，可调整保存文件名。每个文件最多 20 MB，同名不同内容不会覆盖，可换名再传。
- 文件预览右上角「下载」可保存不超过 20 MB 的文件。超过 512 KB 的文本不展开预览，可下载查看；HTML 和 SVG 作为文本显示。

此阶段支持浏览、预览和传输，不提供文件编辑、删除、终端或子智能体面板。符号链接和特殊文件暂不开放。项目文件可能包含敏感信息，请仅向可信设备提供网关登录权限。

### Git 面板

「Git」标签显示当前分支，并按未暂存、已暂存、未跟踪和冲突分组。点击文件查看增删高亮与行号；同一文件可分别审阅已暂存和未暂存的内容。手机采用上下布局，差异区可独立横向滚动。

面板只读取当前聊天项目中的变更，SSH 项目在对应服务器读取。上游领先/落后数量来自本地记录，不会自动联网获取更新。点击「刷新」更新状态；切换标签保留聊天草稿和阅读位置。

当前为只读预览，不提供暂存、提交、推送或丢弃修改。文本差异上限为每份内容 512 KB、比较前后合计 8,000 行；二进制、非 UTF-8、过大文件和子模块提示在电脑上查看。冲突文件展示工作区内容，需在电脑处理。

## iPhone 安装

1. 用 Xcode 打开 `mobile/ios/BridgePreview.xcodeproj`。
2. 连接并解锁 iPhone，按系统提示信任电脑。在 iPhone 的「设置 → 隐私与安全性」开启开发者模式，完成重启和确认。
3. 在 Xcode 的 BridgePreview 和 BridgeActivity 两个目标的「Signing & Capabilities」中选择自己的开发团队。Apple 账号登录和签名授权在本机完成，不需要把密码发给任何人。
4. 选择已连接的 iPhone 后运行。若 Xcode 提示缺少 iOS 平台或设备支持，先按 Apple 的提示完成所需组件安装。

个人免费签名的有效期和可用设备数受 Apple 限制，到期后需重新通过 Xcode 安装。此预览不提供可通用安装的签名 IPA。

## 本地构建

Android 构建脚本为 `scripts/build-mobile-android.py`，仅使用项目 `.tmp/mobile-tools` 中已准备好的 JDK、SDK 和 ZXing，不安装全局工具。原生地址边界验证运行 `python3 scripts/test-mobile-urls.py`；网关收件箱测试位于 `tests/test_mobile_events.py`。

第三方依赖与许可证见 [NOTICE.md](NOTICE.md)。

## 系统后台推送开发状态

平台接入与网关分发代码见 [推送配置说明](push/README.md)。当前预览没有 APNs／FCM 项目配置，启用入口会明确提示未配置。普通 APK 不包含 Firebase SDK；可选 FCM 工程需要配置自己的 Firebase 项目，不能把源码接入等同于推送已接通。

两端连接后右上角更多提供通知、外观和手机设置；聊天列表底部保留账号信息与返回电脑列表，具体聊天页隐藏底栏。通知页可清空当前电脑在本机的历史记录，新事件仍正常接收。
