# macOS 平台维护

- 本目录负责应用包标识与可执行文件解析、同用户进程、Launch Services 启动/退出、Claude 活跃 profile 路径发现，以及 Swift 原生助手。
- macOS 专项问题优先在本目录修复。不得反向导入 `bridge.clients` 或 `bridge.features`；应用启用、账号切换、任务状态、授权和重启决策仍在共享业务层。
- 保留 `.app` 包标识与实际可执行路径验证；读取进程命令时保留完整路径和空格，不用产品显示名代替应用身份。
- GUI 启动使用现有 Launch Services 路径，保留调用方指定的环境和用户目录。不能改成网关直接启动内置 CLI，或让客户端继承网关的隐私身份。
- Claude 的 profile 发现只读指定应用的打开文件路径，不读取 Cookie、令牌或其他 profile 内容。Swift 助手只操作选定客户端，权限与取消结果交还共享接入层。
- 批量状态展示可合并原生查询；发送退出或重启操作前仍必须让共享入口重新核验进程，不能复用展示缓存。
- `posix/` 的进程与终端实现同时服务 Linux。修改共享部分时核对 Linux 和 Windows 对终端公共方法的依赖，并保留原生助手构建/资源路径一致性。
