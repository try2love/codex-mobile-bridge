# Windows 平台维护

- 本目录负责 Windows 安装发现、同桌面会话进程查询、窗口退出、进程启动、命名管道、ConPTY，以及 Claude C# 原生助手与其调用协议。
- Windows 专项问题优先在本目录修复。不得反向导入 `bridge.clients` 或 `bridge.features`；账号、连接状态机、任务空闲检查、授权和重启决策留在对应共享业务层。
- 保留 Windows 路径大小写语义、当前桌面会话筛选和精确可执行文件身份。退出操作不得扩展到其他 profile、渲染进程所属应用或未核验的运行时。
- `transport.py` 必须保留原始字节流与可取消 I/O；取消完成前不得关闭仍在使用的句柄，也不得在这里添加第二套消息封装。
- `terminal.py` 使用 ConPTY（Windows 10 1809+）；它复用了 POSIX 终端模块中的部分公共方法。修改输入确认、游标、尺寸或关闭行为时核对两端，不复制独立业务规则。
- Claude 的取消、重试和超时协调在共享接入层；C# 助手只操作指定的应用窗口，不能据“脚本已提交”推断连接或认证成功。
- 更新相关 Windows fixture 与原生验证。仅在其他系统运行模拟测试时，如实说明尚未完成 Windows 实机验证；不以目录拆分或单元测试代替打包验证。
