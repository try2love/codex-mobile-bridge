# 紧凑输入区手动验收

准备：运行本分支网关页面；原生专项需本分支构建的 Android/iOS App。使用可丢弃的测试聊天，分别准备空闲、运行中、不支持 Plan/Goal 的会话。不在真实任务中测试发送和停止。

## 页面与快捷入口

1. 在 375×812、768×1024 视口分别使用浅色和深色主题，打开 Codex 与其他 Agent 聊天。
2. 检查工具栏仅保留权限、模型与思考强度、上下文圆环及有实际内容的状态入口。长模型可以截断，思考强度可读，完整值可从模型控件查看。无常驻提醒、Skill、发送方式或收起输入区按钮，无横向溢出。
3. 输入草稿，点击「＋」。应按能力显示拍照、选择照片、选择文件、宿主项目引用、Skill、Plan/Goal；不支持的操作不能执行。关闭菜单后草稿不变。
4. 清空正文后输入 `$`：打开现有 Skill 选择器；选择、移除及搜索正常，不发送消息。输入 `/` 或 `/plan`、`/goal`：显示候选，键盘或点击选择后显示模式标签；点标签可清除。Escape 关闭候选，清空再输入可重新打开。中文输入法组合中不执行命令。
5. 切换会话再返回，检查正文、引用、附件、Skill 和工作模式；选模式不会发送消息。

## 原生相册、相机和文件

1. 先保留一份草稿和附件，依次点击三个独立入口。照片应打开系统图片选择器；拍照应打开系统相机；文件应打开系统文件选择器。照片支持多选，拍照为单张。
2. 首次拍照允许权限并完成拍摄：只加入拍摄的图片，不接受相机返回的其他 URI。拒绝权限、取消拍照、返回相册或文件选择器：原草稿和附件不变，可再次打开。
3. 上传中保留缩略图和进度，失败可重试；删除附件不影响其他附件。原有单文件、总量和个数限制继续生效。
4. 选择器打开后离开当前会话或断开电脑连接，再返回选择结果：结果不能进入新会话。测试相机授权中断、快速取消重开及切换电脑后迟到的回调。
5. Android 13+ 验证 Photo Picker，旧版验证原生图片选取；iOS 18.4+ 验证三个指定控件，旧版验证 WebKit 的 accept/capture 系统行为。平板也验证控件呈现及取消。

## 发送与恢复

1. 空闲时发送一条带唯一标记的测试消息：只发送一次；运行中再次发送，应按该客户端支持的队列处理，排队期间 Plan/Goal 选择不可用且队列请求不携带即时 workMode；未提供 queue 时不会擅自改为 steer。
2. 使用合成断网夹具制造未知发送结果，重新连接并切换状态：未确认记录仍使用原 ID，不自动重放；新编辑的草稿不被迟到的确认清除。
3. 当前客户端不允许的模式不能从键盘 Enter 或直接提交绕过。Plan/Goal 的能力、目标已有状态、附件限制继续生效。

清理：删除测试聊天和测试附件，恢复原主题；撤销仅为专项测试授予的权限。合成浏览器夹具不连接真实 Agent。执行过程折叠不属于本次验收。
