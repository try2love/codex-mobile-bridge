额外 HTTPS 地址（高级）

这是网关的访问地址允许列表。只有你已在其他地方配置好 HTTPS 反向代理或隧道，并且需要额外域名访问时，才在这里填写，例如 https://codex.try2love.com。填写地址不会创建隧道、配置 DNS 或申请证书；代理仍须保留该域名的 Host。上方连接配置中的固定域名会自动加入，无需重复填写；只用局域网或临时 Cloudflare 时留空即可。

登录验证

普通网页登录默认 12 小时；0 表示不自动过期。网页记住登录后，使用时自动续期，闲置 7 天后过期。手机 App 登录或扫码后持续信任。修改账号、密码、登录方式或撤销设备会使登录失效。

浏览器可能清理长期未使用的登录凭据；“不自动过期”表示网关不设到期时间。

登录设置保存后，在下次启动网关时生效。

登录安全通知

默认开启，使用已启用的通知通道。关闭通知不影响自动封禁；仅可在电脑 App 的登录设备中解除封禁。

网关启动与入口通知

首次接入与测试

  1. 选择手机推送方式

    iPhone 推荐安装 Bark，Android 可使用 ntfy。允许系统通知和锁屏显示；两个通道可以同时开启。

  2. 填写接收信息

    Bark：填写手机 App 首页推送地址中的服务地址与 Device Key。ntfy：生成随机主题，并在手机订阅相同服务与主题。

  3. 保存，再发送测试通知

    开启需要的通道，点击底部“保存配置”，再分别发送测试通知。请在手机确认收到；服务接受不等于手机已收到。

  4. 开启聊天提醒

    启动网关，在手机浏览器刷新并打开聊天，点击“提醒”，勾选“开启聊天提醒”并保存。随后让 Codex 提出一次选择，锁屏检查是否收到待确认通知。

聊天提醒的测试提示词

请用提问工具让我选择“继续测试”或“结束测试”，等待我的回答，不执行任何命令或文件操作。

测试通知只检查手机接收；聊天提醒还需要电脑、网关、原 Codex App 及相关 SSH 连接在线。

收不到通知或打不开聊天？
  • 先核对 Bark 服务地址与 Device Key，或 ntfy 服务地址、主题和 Token；自建 Bark 的设备需在该服务注册。
  • 服务已接受但手机没提示：检查系统通知权限、专注模式和手机网络。Android 还需允许 ntfy 在后台运行。
  • 通知能收到但聊天打不开：保持网关在线。局域网链接需要手机在同一网络；外网访问需要手机可达的 HTTPS 入口。

Bark 推送 · iPhone

例如推送地址 https://api.day.app/你的密钥，服务地址填 https://api.day.app，Device Key 只填你的密钥。支持官方和自建服务；请勿分享密钥。

PushPlus

使用微信登录 PushPlus、关注服务号并完成实名认证，复制个人资料中的 Token。勾选启用并保存后发送测试通知，再在需要提醒的聊天中开启提醒。

PushPlus 需付费实名认证，最低 3.9 元；认证后可使用基础额度，无需另购会员。费用以官方页面为准。

微信渠道普通实名用户每天 200 次请求、每分钟 5 次；相同内容每小时最多 3 条，失败请求也计入额度。超限可能暂停推送。

ntfy 推送 · Android

在手机 ntfy 订阅相同服务与主题。公共匿名主题的 Token 留空；受保护主题按服务要求填写。

公共匿名主题没有访问控制，知道主题名的人可读写。请使用随机长名称，首测保留“显示聊天标题”为关闭；正式使用可选择受保护主题。

请先在手机 App 保存对应网关。Bark 等通道可跳转到 App；未安装 App 时请关闭此选项，继续使用网页链接。

手动填写的跳转地址优先；留空自动选择网关入口。局域网链接需要手机在同一网络。临时域名变化后，旧通知的链接可能失效。

Cloudflare 组件

桌面 App 已内置 cloudflared，临时和固定隧道均可直接使用。添加连接请前往“网络与登录”。

高级：自定义程序与故障修复

从 Cloudflare 官方 GitHub 下载适配本机的程序并核对 SHA-256，安装在网关数据目录。无需管理员权限，不修改系统 PATH。下载通常需要几十秒，最长等待 3 分钟。

下载或连接失败？

无法访问 GitHub：检查电脑网络或系统代理，稍后重试；也可打开官方教程，下载对应系统与架构的程序。Mac 解压后选择 cloudflared，Windows 选择 cloudflared.exe，再检测并保存。

程序已就绪但隧道失败：查看“运行日志”中的 Cloudflare 部分。网络需允许向外连接 TCP 7844；网关启动后局域网可独立使用，无需等待临时 HTTPS。

登录设备

每条记录代表一次浏览器登录。撤销登录会要求重新验证；封禁 IP 会同时阻止使用该 IP 的所有设备，包括重新登录。

自动封禁 IP

同一 IP 连续输错密码 5 次后永久封禁，重启不会清除。解除后恢复 5 次尝试；白名单不会绕过自动封禁。

网页无法读取网卡 MAC。手机可能使用私有 MAC，IP 也会随网络变化；共用公网 IP 的设备会一起受到 IP 规则影响。

IP 访问规则

黑名单优先。规则保存后立即生效，被排除的登录会被撤销。规则不影响电脑端管理，可在这里解除限制。

代理 IP 设置（高级）

仅在使用 NAS 等 HTTPS 反向代理时填写直连网关的代理 IP。代理必须覆盖或追加 X-Forwarded-For；本机 HTTPS 隧道自动受信任。未正确转发时显示代理 IP，封禁它会影响所有经该代理访问的设备。
