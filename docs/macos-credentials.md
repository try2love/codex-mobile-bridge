# macOS 网关凭据

macOS 网关将保存的 SSH 密码、私钥口令、隧道令牌和 ZCode 官方登录写入资料目录的加密文件。更新或重新编译 App 后，继续使用同一资料目录即可恢复，无需再次授权网关访问钥匙串。

已有旧凭据在启动时保留。需要使用时，在“网络访问”的连接卡点击“迁移旧连接凭据”，或在 ZCode 官方远控管理中点击“迁移旧登录”。这次主动迁移可能需要一次原钥匙串授权；也可以重新填写连接凭据或重新登录。迁移失败会保留旧记录。

备份时保留整个网关资料目录，尤其是 `.credential-vault/key`、加密凭据和 ZCode 登录文件。密钥丢失后不能从密文恢复密码；网关会停止覆盖。目录和文件限制为当前系统用户访问。同一用户下能读取整个资料目录的程序也能取得密钥。

旧系统条目会保留；ZCode 迁移另存 `zcode-official-auth.legacy.enc`。回退旧版本前应正常退出网关并备份资料目录，再恢复对应旧版本的登录备份。新保存的凭据不保证能由旧版本读取。

应用内更新备份会同时保留网关凭据主密钥、连接密文、ZCode 登录和旧登录备份。已有新格式凭据时，应用内切换到 Preview 3 或更早版本会提前停止；这些版本无法读取新格式，数据格式标记相同也不表示凭据兼容。旧系统凭据仍保持原格式时不受此限制。手动回退仍须按上文先完整备份并恢复旧凭据。
