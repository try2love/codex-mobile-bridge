# 通用额度展示

聊天模型按钮旁的小环表示当前接入报告的剩余额度。模型设置和账号页使用同一套额度池和窗口详情：5h、7d、1d 等标签按实际窗口显示；只有每周额度的模型保留每周列位置。圆环不表示聊天上下文占用。

点击模型按钮可查看额度池；点击额度池或账号页模型行展开剩余/已用比例、精确恢复时间和共用模型。ZCode 等提供实际 token 数量时同时保留剩余量与总量。没有窗口或有效百分比时不补造 0%；缺失窗口不冒充已耗尽。

| 接入 | 当前展示范围 | 查询方式 |
| --- | --- | --- |
| 本机 Codex 默认或独立配置 | 聊天工具栏、模型设置、账号卡片 | 前台按已有五分钟缓存读取，可手动刷新 |
| Antigravity | 当前模型工具栏、模型列表、原生共享额度池 | 新原生接口的额度缓存为 60 秒；模型面板可见时每分钟重新读取 |
| Claude | 账号页已有额度快照 | 只在用户点击查询时请求最新额度 |
| ZCode | 账号页按模型分开的每日额度与 token 数 | 沿用现有原生查询和账号核验 |
| DeepSeek / API | 原生提供的余额或额度 | 余额不换算为百分比；没有额度来源时不显示额度环 |

各电脑、接入配置、账号及 Antigravity 原生来源保持隔离。切换后不使用旧请求覆盖新账号。Antigravity 仅采用原生明确提供的模型成员关系；不能确认对应关系时，额度池仍可查看，模型旁不猜配。

读取失败时保留同账号的成功快照并标记未更新；账号或进程变化时清空原缓存。模型目录时间与额度查询时间分别显示。预计恢复时间已经过去，仅显示等待刷新，不代表额度已经恢复。旧版 Antigravity 不支持新接口时沿用原来的单窗口信息。

本地源码与浏览器夹具已验证展示和状态隔离；真实 Antigravity 2.34 的额度响应及 Android/iOS 真机交互仍需验收。
