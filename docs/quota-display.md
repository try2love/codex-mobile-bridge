# 通用额度展示

聊天输入区的“剩余额度”工具表示当前接入报告的额度，默认放在模型工具旁。可在工具栏“定制”中移动到上下栏左右四个位置、收进工具面板或隐藏，也可选择仅图标、仅文字或图标加文字。仅图标显示额度环，仅文字显示窗口与剩余比例。模型设置和账号页使用同一套额度池和窗口详情：5h、7d、1d 等标签按实际窗口显示；只有每周额度的模型保留每周列位置。圆环不表示聊天上下文占用。

点击“剩余额度”只打开额度详情，包含额度池、恢复时间、查询更新时间和刷新入口；模型设置中原有的额度区仍保留，两处显示同一份数据。点击额度池或账号页模型行展开剩余/已用比例、精确恢复时间和共用模型。ZCode 等提供实际 token 数量时同时保留剩余量与总量。没有窗口或有效百分比时不补造 0%；缺失窗口不冒充已耗尽。

| 接入 | 当前展示范围 | 查询方式 |
| --- | --- | --- |
| 本机 Codex 默认或独立配置 | 聊天工具栏、模型设置、账号卡片 | 前台按已有五分钟缓存读取，可手动刷新 |
| Antigravity | 当前模型工具栏、模型列表、原生共享额度池 | 新原生接口的额度缓存为 60 秒；模型面板或额度详情在前台打开时每分钟读取缓存 |
| Claude | 账号页已有额度快照 | 只在用户点击查询时请求最新额度 |
| ZCode | 账号页按模型分开的每日额度与 token 数 | 沿用现有原生查询和账号核验 |
| DeepSeek / API | 原生提供的余额或额度 | 余额不换算为百分比；没有额度来源时不显示额度环 |

各电脑、接入配置、账号及 Antigravity 原生来源保持隔离。切换后不使用旧请求覆盖新账号。Antigravity 仅采用原生明确提供的模型成员关系；不能确认对应关系时，额度池仍可查看，模型旁不猜配。

读取失败时保留同账号的成功快照及其原更新时间并标记未更新；成功响应已不再提供额度时清除旧值。账号、接入或进程变化时清空原缓存，旧请求不能覆盖新作用域，已打开的额度详情也随之关闭。模型目录时间与额度查询时间分别显示。预计恢复时间已经过去，仅显示等待刷新，不代表额度已经恢复。旧版 Antigravity 不支持新接口时沿用原来的单窗口信息。

额度显示独立于[额度恢复后自动继续](quota-continuation.md)。能显示额度不代表该接入支持自动继续，展示缓存也不用于批准任务派发。自动继续仍默认关闭，仅支持已说明的本机默认 Codex Desktop 范围。

本地源码与浏览器夹具已验证展示和状态隔离；真实 Antigravity 2.34 的额度响应及 Android/iOS 真机交互仍需验收。
